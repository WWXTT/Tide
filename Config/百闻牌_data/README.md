# 阴阳师：百闻牌 卡牌数据

数据来源：<https://ssr.163.com/cardmaker/>（网易《阴阳师：百闻牌》官方配卡站）。

## 关键结论（为什么之前「直接拔是空壳子」）

这个站是纯前端 SPA，网页 HTML 里只有 `<div id="app"></div>` 空壳，卡牌数据既不是接口返回、也不是图片里存的文字，而是**完整硬编码在前端 JS bundle 里**：

- 主 bundle：`https://ssr.res.netease.com/pc/zt/20191112204330/js/index_4539655c.js`
- 卡库是其中一个大数组 `a = [{id, name, role, type, xiyoudu, stage, ll, sm, desc, keyword, ...}, ...]`（约 2009 条）。

图片只是渲染层（`data/card/{id}.png`），真正的结构化数据（卡名/类型/稀有度/等级/力量/生命/效果/关键词）全在这个数组里，直接解析 JS 即可，无需 OCR、无需跑接口。

## 文件清单

| 文件 | 说明 |
|------|------|
| `百闻牌_卡牌数据_全量.json` | 全量 2009 条（含旧版/复刻/皮肤/协战，带 `superseded_by` 指认新旧关系） |
| `百闻牌_卡牌数据_当前.json` | 去重后的当前可玩卡 1971 条（去掉皮肤 4 张、旧版复刻、协战重复归属） |
| `百闻牌_效果列表.md` | 按式神分组的可读效果表（1971 张） |
| `关键词列表.txt` | 388 个关键词（来自 `keyword` 字段拆分） |
| `下载卡图.py` | 批量下载卡图与式神头像 |

## 字段说明

| 字段 | 类型 | 含义 |
|------|------|------|
| `id` | int | 卡牌 id（`role*100 + 序号`；重做卡新版 id 尾数 +30） |
| `name` | str | 卡名（中文） |
| `role` | int | 所属式神 id |
| `shishen_name` | str | 所属式神名（由 `type:"式神"` 卡反查） |
| `type` | str | 卡牌类型：`式神`/`法术`/`战斗`/`形态`/`结界`/`衍生`/`觉醒`/`协战` |
| `xiyoudu` | str | 稀有度原始值：`R`/`SR`/`SSR`/`""`（式神）/`SKIN`（皮肤） |
| `rarity` | str | 归一化稀有度：`R`/`SR`/`SSR`/`N`（式神与无稀有度卡记为 `N`） |
| `stage` | int\|null | 卡牌等级 |
| `ll` | int\|null | 力量 |
| `sm` | int\|null | 生命 |
| `desc` | str | 效果描述（含标记语法，见下） |
| `keyword` | str\|null | 关键词，逗号分隔 |
| `is_skin` | bool | 是否为皮肤版（`xiyoudu=="SKIN"`） |
| `is_teamup` | bool | 是否为协战牌（`type=="协战"`） |
| `superseded_by` | int\|null | 旧版/复刻/协战重复 → 指向新版 id（仅全量文件有） |
| `alt_roles` / `alt_role_names` | list | 协战牌的另一归属式神 id / 名称 |
| `verser` / `version` / `ghxh` | 混杂 | 原始版本标记字段（初版/焕新标记），一般可忽略 |

## desc 标记语法（原始数据格式）

`desc` 里用到一套内部标记，解析/清洗时需留意：

| 标记 | 含义 | 示例 |
|------|------|------|
| `#r` | 换行 | `瞬发#r投射` |
| `#[xxx]` | 高亮词（力量/生命/护甲/能量/战力/赏金/破甲…） | `+2#[力量]` |
| `@id` | 关联卡牌引用 | `@1920103` |
| `&id` | 关联卡牌 id（尾随） | `&6670802` |
| `&N+{变量}&` | 动态数值模板 | `&2+{法强值}&` |
| `$…$` | 条件/模板表达式 | `$（得&(buff技能(1003,))&）$` |

## 去重规则

全量 2009 条 → 当前 1971 条，去掉了：

1. **皮肤版 4 张**：`xiyoudu=="SKIN"`（如 `10109 妖刀万华(SKIN)`）。
2. **旧版/复刻**：同式神同名卡，id 尾数个位（旧）被尾数 +30（新）取代，旧版标 `superseded_by`。
3. **协战重复归属**：17 张协战牌各归属 2 位式神，共享同一 id，保留一条并记 `alt_roles`。
