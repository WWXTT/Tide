【TargetKinds】TargetKind.cs 17 序号（只许尾部追加、永不重排），逗号分隔、升序书写：
  0  = Self（仅自身——Grant族/沉睡类自我效果）
  1  = 己方有生命单位（战场生物+己方角色）      2  = 对方有生命单位
  3  = 己方无生命单位（结界等非生物）            4  = 对方无生命单位
  5  = 己方手牌                                  6  = 对方手牌
  7  = 己方牌库                                  8  = 对方牌库
  9  = 己方坟场                                  10 = 对方坟场
  11 = 己方除外区                                12 = 对方除外区
  13 = 己方元素池（地牌）                        14 = 对方元素池
  15 = 己方发动区（反制指向落点）                16 = 对方发动区
写法：null 或 ""（空串）= 无目标原子（不参与卡的组合域交集）；"1,2"=逗号分隔多值。
★ 隐藏区（7/8 牌库、6 对方手牌）域的原子：卡上 SelectionMode 用 None(-1) 自结算，
  不弹目标选择；公开区（战场/坟场）才用选一/选多档（0/1/3/4）。

【SelectionMode 六值（2026-09-16 定案）= 数量（1/N/全）× 范围宽（单/多）】
  0=单范围选一个（域={Self} 即源卡自身——旧 Self 溶解）
  1=单范围选多个（所选必须同范围——构筑期域宽校验保证）
  2=单范围全取          3=多范围选一个      4=多范围选多个      5=多范围全取
  规则：一个 {target} 只能从一个范围选择——0/1/2 要求组合域恰为单一 TargetKind，
  多范围域须用 3/4/5（构筑期校验，违反报错）。目标随机为正交标志 random（0/1），
  不再占枚举位（随机1个=0/3+random、随机N个=1/4+random、随机全部≡5 无意义）。

【TargetKinds × AoE 分区全体（2026-09-16 定案）】
  AoE 不用专用原子：原子行 TargetKinds 指向分区 + 卡上效果级全取档（2 单范围 / 5 多范围）
  = 该分区全部对象（候选全取、不弹选择、帷幕/扰魔不过滤=波及语义）。三个标准组合：
    1    = 己方有生命单位全体（含己方角色）        —— 用 2
    2    = 敌方有生命单位全体（含对方角色）        —— 用 2
    1,2  = 双方全体                                —— 用 5
  固有全域两行 SweepDamage/SweepHeal（TargetKinds="1,2"）即「双方全体」的一等实例，
  converter 无条件强制 WholeUnion(5)、计价数量 ×1（范围溢价已含 BaseCost）；
  普通原子 + 全取档的分区全体按期望 4 目标计价（CostDerivation.FullModeExpectedTargets）。
★ 单体 AoE 混写笔误：只要单体就别配全取档——全取是"整分区"不是"目标数上限"。

【MountKinds】可装载范围（MountKind.cs 10 值，CSV 多选同 TargetKinds 惯例；只许尾部追加）：
  0 = ActiveEffect   可作主动效果（效果栏原子：登场/触发/启动式）
  1 = Keyword        可作关键词（卡面自带印刷，如剧毒/嘲讽/回响）
  2 = Counter        可作指示物（效果=赋予指示物，指示物承载持续规则）
  3 = BranchTrunk    可作条件分支主干（产出可被 OutcomeGate 条件观测：伤害/治疗/宣言/预言族）
  4 = BranchReward   可加入分支（条件达成的奖励原子）
  5 = GrantOnCreature 可赋予生物（Grant 类授予的合法目标）
  6 = GrantOnSpell   可赋予法术（回响等法术侧关键词）
  7 = RandomMount    可挂载数值随机幅度（伤害/治疗族+限制型指示物层数随机，2026-09-13）
  8 = TriggerCapImmutable 触发上限不可修改（**少数**，如坚韧）：触发式恒无每回合上限、
      组合期不可加限；其余原子默认可修改且默认上限=一回合一次
  9 = FreeBranchTrunk 自由分支主干（拼点/运势/倒计时——**只可落入合成器主干槽**，
      写 header.EngineKind/EngineParam；MountKinds=9 的行必须显式只写 9，不与其余位混挂）
写法：CSV 逗号分隔（"0,4" = 主动效果+分支奖励；"" 空串=未声明，消费方自行兜底）。
★ 消费方：装载校验（CardLoader）/触发上限解析（CardEffectConverter.MountHasFlag(8)→
  TriggerLimitPerTurn 恒 -1）/合成器可拖拽目录（ComposerCatalog 按 MountKinds 驱动检查器）。
★ MountKinds **不进表指纹**（CardIdentityService.TableFingerprint 只哈希 EnumName/ManaList/
  TargetKinds/TargetFilter/Polarity）——改它不触发卡身份换血/manifest 作废/重训，
  只影响装载校验与合成器可挂范围。

【TargetFilter】域内属性细化（逗号组合 = AND 语义；null/空 = 无过滤）：
  NoRole      = 仅生物（排除角色）
  Mortal      = 凡躯（滤除神佑持有者——死亡族表行都带它）
  Stealth     = 仅潜行中         Untargetable = 仅辟邪持有者
  Untapped    = 未横置           Tapped       = 已横置
  Damaged     = 已受伤           Friendly / Enemy = 己方 / 对方
  Player      = 仅角色（现为 no-op 保留位）
  分区名 no-op 保留位：Hand Graveyard Deck Exile Battlefield Activation
  属性比较式：Power>5 / Life<=3 / Power=2 等格式
★ 新击杀效果 = 表行带 Mortal 即可，零引擎改动。

【其它字段】
  EnumName   = 中文短名（装载后作为显示名，进表指纹——改名=身份换血）
  DisplayName= 展示模板（装载后作为描述；ID 列由它哈希：sha256(去首尾空格)前8位hex）
  EffectColor= 计价落色：Red / Blue / Green / White / Black / Gray（不进表指纹）
  BaseCost   = 锚价（单价，×Value 计价；进表指纹）
  Polarity   = 极性 [-1,1]：-1 对敌释放有益 / +1 对己释放有益 / 0 中性（进表指纹）

【改表的连锁反应】
  · 改 EnumName / BaseCost / TargetKinds / TargetFilter / Polarity 任一 → 表指纹变
    → 全体卡身份哈希换血 → manifest 作废 → 必须重训 + 重导出
    （改 EffectColor / DisplayName / ID 不动指纹）
  · ID 列不用手写：跑 Tools/重推导测试卡表费用与ID 自动重推；
    DisplayName 撞名 → ID 撞号（工具会告警）
  · 改完表的标准动作：Tools/重推导测试卡表费用与ID → Tools/端到端验证
