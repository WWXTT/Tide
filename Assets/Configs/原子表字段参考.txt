【SelectionMode 六值（2026-09-16 定案）= 数量（1/N/全）× 范围宽（单/多）】

  1=单范围选多个（所选必须同范围——构筑期域宽校验保证）
  2=单范围全取          3=多范围选一个      4=多范围选多个      5=多范围全取
  规则：一个 {target} 只能从一个范围选择——0/1/2 要求组合域恰为单一 TargetKind，
  多范围域须用 3/4/5（构筑期校验，违反报错）。目标随机为正交标志 random（0/1），
  不再占枚举位（随机1个=0/3+random、随机N个=1/4+random、随机全部≡5 无意义）。

【费用构成 ManaList（2026-10-04 位置数组定案——唯一费用列）】
  ManaList   = float 位置数组：**下标 = ManaType 枚举序号**，长度 = 枚举成员数（当前 6）。
               现行枚举序（勿凭直觉，认枚举）：0=灰 Gray、1=红 Red、2=蓝 Blue、3=绿 Green、
               4=白 White、5=黑 Black。例：攻击（灰1）= [1,0,0,0,0,0]——灰在序号 0；
               碾压（红3）= [0,3,0,0,0,0]；时之枷锁锚价（蓝6）= [0,0,6,0,0,0]。
               混合色=多位非零（未来能力，当前 99 行全是单色位）；null/空 = 不计价行。
               计价 = 各色份额 × Value；首个非零下标色即主色（config.PrimaryColor）。
  扩色口径   = ManaType 枚举尾部加成员，数组长度自动跟随（ElementCost.Length 读枚举数）——
               后续扩色只改枚举，表/卡/效果/代码零改动；**枚举序号永不重排**（已序列化的
               int 色键全链保序）。
  落盘同款   = Cards.json costList / Effects.json cost 也是同口径位置数组（154 卡+104 锚价
               已迁移）；运行时全链统一 ElementCost（原子表 config.ManaList / CardData.Cost /
               推导输出 DeriveElementCosts / 支付入口同一类型）。
  历史墓碑   = 旧 EffectColor+BaseCost 两列（2026-09-14 定案合并、2026-09-20 起兜底合成）
               与死列 EffectTier 已于 2026-10-04 随全量数据迁移**从表删除**——BuildConfig
               兜底分支同步移除，新行直接写 ManaList 位置数组即可。
  Tags       = **只读派生列（表里不写）**：BuildConfig 写入首个非零下标色的颜色名字符串
               （"Red"/"Blue"/…）——UI 圆点/ElementAffinity 取色都读它。
