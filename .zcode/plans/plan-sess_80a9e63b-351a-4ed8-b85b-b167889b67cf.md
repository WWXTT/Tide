# HexMap 地形重构计划:垂直侧壁 + 内缩阶梯 + 特征 mesh 预留

> 定稿 2026-09-20。取代现有坡/桥/角落吸收 mesh 设计。
> 特征算法层(河流/道路/植被/存档)沿用桌面旧计划 `ethereal-giggling-dewdrop-agent-a71ce687bfaaccec2.md`,
> 其中"河流整格降高程雕刻"部分被本计划 M2 取代。

## 0. 背景与动机

现有 mesh(HexMeshJob.Part1/Part2):板逐边内缩 + 5×5 平滑坡带 + 等高桥 + 角落吸收三角
(EmitAbsorbedCorner)+ 流式墙/角闭合楔形 + rim 法线融合(NORMAL/TANGENT 双法线)。问题:

- "上小下大"观感;角落吸收/流式闭合产生大量特殊封闭面,正是用户想消灭的"奇怪的封闭面";
- 三地形交汇的角落三角三顶点各持一个地形(W100/W010/W001,HexMeshJob.Part2.cs:313-328),
  内部三权重 ~1/3,HeightBlend3 的 w·strength 抬升互相抵消,逐像素高度差独裁 →
  全局最亮高度图的层吞掉角落——**Y 字形混合问题无法在 shader 公式层修复**
  (flash 两次公式级修改均失败已撤销;根源在 mesh 权重结构);
- rim 融合双法线管线是拉丝/拉伸类视觉问题的温床,维护成本高。

新设计:侧壁分级(小落差内缩阶梯、大落差垂直壁),**全部几何限制在本格自己的扇形区域内,
零跨格角落三角形**。

## 2. 核心几何规格

### 2.1 边分类与有效内缩

EdgeKind 重命名:`{ Equal, Higher, Lower, Boundary, Streaming }`(原 Bridge/SlopeLower/SlopeHigher/…)。
每边有效内缩 l_d:Lower 且 Δe≤2 → IR−L(阶梯边);其余(Lower Δe>2、Equal、Higher、
Boundary、Streaming)→ IR(板全宽)。

### 2.2 板角点——辐射线规则(扇形独立的关键)

板角点 k 落在"格心→名义角点 k"的辐射线上,取相邻两边内缩的较深者:

```
plateCorner_k = center + Corners[k] · ( min(l_{k-1}, l_k) / IR )
```

推导:辐射线与内缩线 l 的交点半径 = 2l/√3 = OR·(l/IR),Corners[k] 长度恰为 OR。
两邻边等内缩时与旧 GetPlateCorner 线线交点重合;不等时角点收在辐射线上,
不戳到浅边——保证相邻扇形共享同一板角点、扇形间互不越界。
板边 = 两角点连线(内缩不等时为斜弦,不是名义边的平行线)。

### 2.3 板构建(BuildPlate 重写)

- 保持双环变异结构:中心 + 内环(变异权重 1)+ 边环(板多边形,权重 0,fade 环带渐变);
  内环角点按 2.2 同规则再内缩 fade(≥5% IR 兜底);
- 法线恒 +Y;rim 融合(StripNormal/EdgeJunction/CornerJunction/BlendRim)与融合法线流
  (TANGENT 通道)整体退役,只留单条 PureNormals 流;
- 顶点扰动(Perturb,世界坐标纯函数)保留——共享线两侧同批点扰动后逐点重合。

### 2.4 阶梯带(Δe∈{1,2},高格生成)

- 顶边 = 本格板边(2.2 角点连线),底边 = 低格名义板边(低格该边全宽,即名义边线);
- 剖面点(带宽方向 s∈[0,L],s=0 板缘 / s=L 名义边;y 从 y_A 降到 y_B):
  踏面 Δe+1 段(每段宽 L/(Δe+1)),立面 Δe 段(每段高 (y_A−y_B)/Δe),交替展开;
- Δe=2 例(总高≈6,L=1.73):踏0.58→立3→踏0.58→立3→踏0.58(巨阶观感;嫌陡调大 L);
- 列方向(沿边)用 EdgeVertices 5 段细分,列端点沿辐射线取值与板角点逐点重合;
- splat:顶 W100(高格地形)→ 底 W010(低格地形)随踏面级渐变;idx=(高,低,低);
  HeightBlend3 在 0→1 干净梯度上工作(楼梯竖向过渡自然);
- 变异权重全 0(与板缘 0 一致,共享线两侧无缝);
- 法线:踏面 +Y / 立面 = 该边水平外法线(逐面常量,直写 NORMAL)。

### 2.5 垂直壁(Δe>2 / Boundary / Streaming / 等高缝壁)

**此构造已实现并通过逻辑推演(2026-09-20 半成品,见 §4),逻辑可直接续用:**

- 顶边 = 本格全宽板缘(名义角,扰动后 5 列),底边 = 同批 x/z 直落到低侧板高(或 bottomY);
- **角柱分段防 T-junction 发丝缝**:壁两端角落的第三方格(N(d−1) 与 N(d+1))板高
  严格落在 (底, 顶) 开区间时,壁按行在该高度分段——同一高度同时覆盖"第三方板角落点"
  与"第三方↔低侧邻格间壁的端点"两类落点(高度同源);流式第三方不分段,其加载后
  本格随邻居标脏重建;
- 多级高差角落 = "烟囱"构造:三条边壁共享同一条角落竖棱(同批扰动 x/z + 同一批分段高度),
  围绕竖棱逐段首尾相接,任何高度组合构造性水密;
- 等高微差缝壁(Equal 且 y_A > y_N):高侧发同构造薄壁(Δy 通常 <1.2),splat A→B 全渐变;
- splat:真实低壁顶行 W100→底行 W010 线性渐变;边界/流式壁恒本格地形;变异权重全 0。

### 2.6 角落封闭——扇形剖面框架(唯一非平凡件)

- 每格 6 扇形(格心 + 边 d 两端角点),扇形 d 的全部几何(板扇形 + 边带)限制在两条
  辐射平面之间;
- 每条边定义"剖面" P_d:沿带宽方向从板缘到名义边的**单调下降折线**
  (等高 = 平线;缝壁 = 名义边处竖直微段;阶梯 = 踏/立交替;垂直壁 = 名义边处竖直长段),
  剖面顶点 = 板角点(两相邻扇形共享同一顶点);
- 角 k 封闭件 = 本格两相邻剖面 P_{k−1}/P_k 在辐射平面内的**"楼梯侧面板"**
  (填充两剖面之间区域,即楼梯侧视挡板)。归属规则须三方对称可算:
  建议剖面底更低者发整块、平手 offset 字典序(旧 WinsCornerPair 精神,
  但面只在本格分界面内,不跨格);
- 名义角点竖棱:三方剖面终点在角柱上的 y_{N(k−1)} 与 y_{N(k)} 之间的竖段,
  由 N(k−1)↔N(k) 那条边自己的几何覆盖(壁/缝壁;若那边是阶梯,其端面侧板补到角柱);
- 阶梯侧面板同样要在相邻边带的分段高度处按行分段(防 T 缝,同 2.5 规则);
- 验收:HexMeshVerifier 水密迭代收敛(不变量:壁面竖直、棱共点、无洞、无重叠)。

## 6. 风险

1. **角落侧面板**(2.6)是唯一非平凡几何:归属规则与分段高度需 Verifier+截图迭代收敛;
2. 阶梯带斜弦(相邻边内缩不等时带顶边为斜线):踏面列端点必须沿辐射线取值、与板角点
   逐点重合,否则板/带共享线开缝;
3. Δe=2 阶梯立面高 3、踏面 0.58(≈79° 巨阶):观感如过陡,调大 blob.SlopeInset;
4. 等高缝壁 Δy ≤1.2:块状错落是设计观感,不是缺陷;
5. Crest 多水位大概率不过 spike → 按预案降级,不阻塞其余里程碑;
6. TTFE-BRG 兼容未知 → spike 前置,必要时改 TTFE 源码;
7. M1 落地到 M2 之间,道路缎带跨高差处会"披挂"下壁(采样器只回板 y)——过渡期外观,不算回归。
