# 快攻 vs 慢速：两套主题卡组 + 自动对战脚本

## 现状结论（已探明）
- `AiBattleDriver.RunFullGame(deck1, deck2, maxTurns)`（`Assets/Editor/AI对战/AiBattleE2E.cs:100`）已支持双方各自卡组、双 SimpleAI 全自动整局、战报自动落盘 `Logs/MatchLog_*.md`，返回 `BattleRunResult(Winner/Reason/TotalTurns/Errors)`——直接复用，不重写对战循环。
- 对战卡组文件 = `{"cards":[...],"deckConfig":{...}}`（`CardLoader.LoadCardsFromText` 解析，id 任意不查池），原子条目 `{refId,value,str,amp,kinds}` 引用现行原子表 `Assets/Configs/AttributeValueConfig.json`（84 行，首列 8-hex ID）。
- 正式池 21 张全 1/1 关键词生物且 12 张效果断链成白板——故两套卡组采用**自包含内嵌效果的新设计**（照旧 Deck_Red/Blue 主题卡组先例），不受断链影响。
- 用户未答复选择项，按推荐执行：新设计主题卡组 + 顺手修 5 处 "Tide/"→"Card/" 路径常量。

## 实施步骤

### 1. 组两套卡组（玩家视角设计）
- **`Assets/Configs/BattleDecks/Deck_Aggro.json` 快攻「赤红疾袭」**（红系，~30 张，曲线 1-3）：低费高效生物（先攻/警戒/吸血类关键词）、直伤法术（DealDamage 打对方玩家）、个别临时加攻；地牌（红费生物）产红，节奏靠前。
- **`Assets/Configs/BattleDecks/Deck_Control.json` 慢速「苍蓝壁垒」**（蓝绿系，~30 张，曲线 2-6+）：圣盾/再生/成长类防御生物、治疗（Heal）、冻结/限制类控制、抽牌（DrawCard）、大费终局生物。
- 原子 refId 全部从现行 `AttributeValueConfig.json` 查表填写（先读表建 EnumName→ID 映射，不沿用旧 id）。
- 过 `CardLoader` 四道校验 + 内容契约（效果栏只放对己有益原子、错边走 Costs Payload）；重复张用不同 id 条目表达；costList 显式声明控制曲线，同时贴近计价锚点避免超模警告刷屏。

### 2. 对战驱动 `Assets/Editor/AI对战/ArchetypeBattle.cs`
- namespace `CardCore.Editor.Tests`（同 AiBattleE2E）；`[MenuItem("Tools/AI 自动对战（快攻vs慢速）")]` + `public static void RunBatch()` 供 `-executeMethod` 无头调用。
- 流程：加载两卡组 → 跑 12 局（奇数局快攻=P1、偶数局换边快攻=P2，maxTurns=100）→ 按 `ReferenceEquals(winner, GameCore.Instance.Player1)` 归座 → 汇总胜率/平均回合/结束原因/错误数 → 写 `Logs/ArchetypeBattle_Report.md` 并 `Debug.Log` 摘要（batchmode log 可见）。

### 3. 启动脚本 `tide_rl/run_archetype_battle.py`
- 检查 `Temp/UnityLockfile`（Unity 未运行时删残留锁）；调 `C:\Program Files\Unity\Hub\Editor\6000.5.10f1\Editor\Unity.exe -batchmode -nographics -projectPath <repo> -executeMethod CardCore.Editor.Tests.ArchetypeBattle.RunBatch -logFile Logs/ArchetypeBattle_Unity.log`；等待退出后打印报告摘要与 Unity 日志中的错误行。

### 4. 顺手修路径断链（5 处字符串 "Tide"→"Card"）
`EffectsLibrary.cs:16`、`CardCatalog.cs:17`、`CardConfigSerializer.cs:23`、`DeckSerializer.cs:19`、`CardPipelineVerifier.cs:5011`——恢复正式表读取与重推导菜单，与本任务无依赖、纯顺手。

### 5. 运行验证
- 跑启动脚本 → 检查 Unity log 无编译错/无 LogError、`ArchetypeBattle_Report.md` 数据完整（12 局全 Completed）。
- 若一侧 12:0 明显失衡，微调一次卡组（调曲线/费用）再跑一轮，最终以数据报告为准。
