# TTFE Global Shaders Controller 精华融入 HexMap 系统

## 背景结论(探索已证实)
- TTFE 精华 = 场景里的 `TobyGlobalShadersController` 单例往 shader 写全局变量:`_SeasonChangeGlobal`(-2~2 春绿/秋枯)、`_SnowAmount`(0~10)、`_Wetness`(0~1)、`_GlobalWindStrength/_StrongWindSpeed/_WindMotion/_WindDirection` + 风型 keyword;交互区域控制 = 每帧写 `_PlayerPosition/_BendRadius/_BendAmountGrass/_BendDirection/_Disturbance` 做球形遮罩踩踏弯曲。
- HexMap 现状:HexTerrain.shader 零天气代码;植被 ECS 散布→BRG 渲染链路完整但 scatterRules 为空、草/石资产无引用无材质;Main.unity 无控制器。
- 已有链路(实测代码):地图初始化 → `HexFeatureGenerationSystem` 生成河/路并填 BFS 距离图 → 置 `VegetationDirty=true` → `HexVegetationSpawnSystem` 自动散布。**初始化自动排布的触发链已存在**;排除机制也已存在:河/路 margin(BFS 距离)、阶梯/侧壁几何规避(落点盘 0.75×InnerRadius ⊂ 板内缩六边形,不落坡带)、壁顶格过滤(maxNeighborElevationDiff)、合适地形(densityPerTerrain 按层)。
- 硬约束:HexMap 植被走 Entities Graphics(BRG),要求 DOTS instancing;TTFE ASE shader 不支持。**已拍板:自研 HexGrass 移植;踩踏交互源预留 Transform 字段、不默认接相机。**

## 实施步骤

### P0 全局驱动层
1. Main.unity 实例化 TTFE 的 `(TTFE) GLOBAL CONTROLLER.prefab`(ExecuteInEditMode,Inspector 可调季节/雪/湿/风,朝向=风向)。
2. 新建 `Assets/Scripts/HexMap/Weather/HexPlayerBendDriver.cs`:public Transform[] players(不默认填)+ 半径/强度参数;无玩家时 `_BendAmountGrass=0`;有则选最近活跃玩家,SetGlobal 写 `_PlayerPosition/_BendRadius/_BendAmountGrass/_BendDirection/_Disturbance`(语义对齐 TTFE PlantInteractionShader 简化版)。

### P1 共享天气 HLSL — `Assets/Art/HexMap/Shaders/HexWeather.hlsl`(新增)
- 声明 TTFE 同名全局 uniform(UnityPerMaterial 之外,照 `_ChunkWorldSize` 模式);缺省 0 = 完全 no-op。
- 片元函数:`ApplyWetness`(变暗+光滑度升)、`ApplySnow`(normalWS.y 朝上掩码 + 程序噪声打破均匀,向 `_SnowColor` lerp)、`ApplySeasonGrass`(枯色 lerp,绿优掩码 saturate((g−max(r,b))·k) 自动只作用草层)。
- 顶点函数(植被专用):`HexWindDisplacement`(移植 TTFE 核心:风向弯曲×高度权重 + 世界坐标噪声阵风 + hash 随机相位 pivot 摆动,自写 ~20 行 2D 噪声)、`HexPlayerBend`(xz 距离球形遮罩压弯)。不依赖草网格顶点色。

### P2 HexTerrain 天气响应(改造)
- `HexTerrainInput.hlsl`:include HexWeather + Properties/CBUFFER 增 `_SeasonDryColor`、`_SnowColor`。
- Forward 与 GBuffer 两个 frag 在 `SampleSplatSurfaceTriplanar` 之后统一调用 ApplySeasonGrass → ApplySnow → ApplyWetness。地形不摆动,无顶点改动。

### P3 HexGrass.shader(新增,植被/石头共用)
- 照 HexTerrain 骨架(ForwardLit/ShadowCaster/DepthOnly/DepthNormals/GBuffer),`multi_compile_instancing` + DOTS.hlsl(BRG 兼容);ShadowCaster 顶点同样加风摆(否则影子不摆)。
- Properties:_MainTex/_Cutoff/_BaseColor/_DryColor/_SnowColor/_SwayPower/_BladeHeight 等全进 UnityPerMaterial;alpha clip + Cull Off 双面。
- 顶点 = HexWindDisplacement + HexPlayerBend;片元 = 季节/雪/湿共用 HexWeather。石头材质用 `_SwayPower=0` 同 shader(绿优掩码自动跳过石头季节色)。
- 建 4 材质:Nettle/Sedge/Camomiles/Stones(贴图已在 Assets/Art/HexMap)。

### P4 初始化自动排布(核心需求:排除道路/河流/阶梯/侧壁,只落合适地形)
- 填 `HexMapFeatureSettings.asset` scatterRules:3 种草(密度只给 terrainIndex 2/3 草地层)+ 石头(全陆地层低密度,_SwayPower=0)。
- 每条规则显式配置排除参数:
  - **河流/道路**:`riverMarginCells`/`roadMarginCells` ≥ 2(硬排除,含缓冲;路桥上无植被);
  - **阶梯/侧壁**:`maxNeighborElevationDiff` 草收紧为 1(相邻落差>1 的格不放=避开壁顶缘与台阶带),石头放宽 2;
  - **落点级保证**:沿用现有 0.75×IR 内缩盘(不落坡带/侧壁),不自建新逻辑;
  - **合适地形**:densityPerTerrain 只填草地/陆地层,沙滩(Sand idx7)雪线(Snow idx9)悬崖层为 0/缺项。
- 验证初始化时序:进 Play → 河路距离图先于散布就绪(现有 UpdateAfter 链已保证,跑通确认即可);若发现初始化先散布后生成河路的竞态,修系统顺序。

### P5 验证
- 新建 `Assets/Editor/HexMap/HexWeatherVerifier.cs`(`Tools/HexMap/验证天气系统`,照 HexMeshVerifier 形态),断言:
  1. 场景有 TTFE 控制器,`Shader.GetGlobalFloat(_SeasonChangeGlobal)` 与控制器值一致;
  2. HexScatterInstance 实体存在且世界位置非原点(BRG 正常);
  3. **排除断言**:遍历全部散布实例,无一落在河/路 margin 内(对照 RiverDist/RoadDist)、无一在 maxNeighborElevationDiff 超标格、地形层 ∈ 规则允许层;
  4. HexGrass 材质 shader 有效。
- UnityMCP 截图对比:季节 -2/0/+2、雪 0/5/10、湿 0/1、风弱/强、草摆动帧间差异、初始化后植被分布远景(目视确认路/河/梯/壁无植被)。

## 风险
- BRG + 材质属性运行时变更:交互参数全部走 Shader.SetGlobal 规避。
- 草网格无顶点色数据:变异改用世界坐标 hash,不依赖。
- HexTerrain 调试通道与天气叠加显示:验证截图避开 debug 模式,必要时 debug 分支跳过天气。
