## 1. 目标架构（二期）

```
本地引擎事件 ──▶ LocalFilmSource ──┐
服务器下行   ──▶ NetFilmSource  ──┼──▶ BattlePlayhead（LiveData / Replay）
剧本文件     ──▶ ReplayFilmSource ─┘        │
                                    IBattleStageSink（战斗屏 / 观战屏 / 自检桩）
```

### 1.1 播放器只有两种模式

- **LiveData**：生产者边产边投帧；帧内 `PreOps→View→Ops→Lines→Combat` 全部经 `IBattleStageSink` 执行；
  帧间节拍（本地 900ms / 联机 350ms，积压 >6 帧压缩停顿）；队列空且回合未完=`WaitingForInput`。
- **Replay**：剧本一次性投帧；同一条帧体；末帧 `End` 收卷；**不询问输入**；支持 `SeekTo`。

> 旧 `Live`（闭包+日志 Hold）在阶段 A 删除，不保留双轨。

### 1.2 数据面（联机）

- **`EventFeed { None, FxOnly, Full }`**（`INetChannel` 字段，替代 `WantsEvents` bool）：
  - AI 填位客户端 = `Full`（`NetClientBrain` 观察用，现状不变）；
  - 人类座位 = `FxOnly`（演出白名单事件 + 三个结算边界；行流承担日志）；
  - 观战 = `FxOnly`（全量行流 + fullInfo 快照已给全信息；演出只需事件载荷）。
- `FlushDownlink` 事件段按 **演出白名单** 过滤（见 §3-B 表）；行流段不变。
- **`MatchLogFull = 137`**（`MsgNetLogBatch` 复用载荷）：终局在最后一拍事件/行之后，按座位发全量无遮蔽行
  （`redactHidden=false, redactEffectSummary=false`）；客户端 `OnLogFull` 按 `EventId` 回填 `FullText`。
- **协议 `Version = 18`**（当前 17；135 行流、136 座位切换之后新增 137）。TagTable 走
  `RefreshMemoryPackOrder` 生成，不手改。

### 1.3 联机录制与回放

- `NetFilmSource` 在 LiveData 播放同时录制 `BattleFilm`（帧=View+Lines+PreOps/Ops+Combat）；
- matchId **客户端对局开始生成一次**（`EncounterStore.NewMatchId()`），同时用于：
  ① `BattleFilmStore` 文件名；② 终局 `EncounterRecord.matchId`（当前 `NetOnMatchSummary` 用
  `summary.MatchId`，服务器不分配 → 改为复用本局 id）；
- 终局 `MatchLogFull` 到达后按 `EventId` 回填 `FullText` 并重写 film；未到达（断线）退回遮蔽版；
- 回放入口：大厅 `btn-replay`（预制体已有）——选中历史行且 `BattleFilmStore.Has(record.matchId)` 才可点；
  点击 = `BattleEntry.Mode=Replay; ReplayFilmId=matchId` → 同一 `BattleScreen` 复盘屏。

### 1.4 观战

- 观战连接 = `Network` 模式同一战斗屏；`viewerSeat=-1`；
- `NetFilmSource` 与玩家端完全同构（FxOnly 事件 + 全量行 + fullInfo 快照）；
- 观战不录制 film（v1；避免每个观战者落盘）；中途加入从加入点起（行历史/快照已具备）。

### 1.5 输入等待

- 仍在对局驱动层（`TargetSelectionService`/`ResponseWindowService`/`GameActions`）；
- 播放器只表达 `WaitingForInput`（队列空且回合未完），回放永不等待；
- `IBattleInputGate` 继续只预留（不在二期实现）。

## 3. 阶段任务

### A — 本地实时切 LiveData（删旧闭包与日志 Hold）

**目标**：本地实时与回放走**同一个帧体/执行器**；视觉、时序、战报逐字不变。

**改动**
1. `BattlePlayhead`：
   - 新增 `PlayMode.LiveData`；`Enqueue(frame)` 在 LiveData 下走 `RunFrameAsync`（抽自 `RunReplayFrameAsync`：
     PreOps→View→Ops→Lines→Combat→等视觉→节拍）；`Lines` 由 `stage.AppendLines` 入列（不再 `ReleaseUpTo`）。
   - 删除旧 Live 分支（`DrainDeferredPresentationOps`/`ReleaseUpTo`/`PerformCapturedNow` 的 live 调用）；
     `FinishCore` 去掉 `DrainDeferredPresentationOps`。
   - `WaitingForInput` 暴露（队列空且 `!_sawRoundEmpty`）。
2. `BattleProjector`：
   - 删除 `DeferOrRun` / `_deferredPresentationOps` / `DrainDeferredPresentationOps` / `SuppressAutoFlush` 的
     “延迟演出”用途（`SuppressAutoFlush` 仅保留“播放期不自动对账”的置脏抑制，改名 `SuppressAutoReconcile` 可选）。
   - 每个演出钩子只构造 `BattleFxOp` → `LocalFilmSource.Capture`（现有双轨录制的删除闭包一侧）。
3. `LocalFilmSource`：
   - 建帧时填 `Lines`（`MatchLogService.Appended` → `MatchLogLineStream`，本地 `redact` 全 false）与 `FrameIndex`；
   - `Enqueue` 到播放器（LiveData），不再依赖 `LogBoundary`；`BattleLogController` 不再 `Hold/Release`。
4. `BattleLogController`：删 `Hold/_holdBase/_heldEntries/ReleaseUpTo/ReleaseAll/IsHeld`；
   新增 `AppendLines(IReadOnlyList<BattleLogLine>)`（时序整理保留：建局静默/自然抽挂起/连锁开合）；
   `_log.IsHeld` 探针（HP 读数）改 `playhead.Busy`。
5. `BattleScreen`：Live 也创建 `IBattleStageSink`（复用 `ReplayStageSink` 的视图/执行器/时间轴；战斗=
   `CombatChoreographer.PerformCapturedNow`，保持本地精度）；`_localSource` 投帧。

**不动**：`CombatChoreographer` 捕获/开演（本地战斗演出的精度来源）；教学/AI 节奏语义；C 案行流。

**验收**
- 编译 0 error；木桩/普通/预组对战：入场/伤害/回复/死亡/拼点/运势/疲劳/指示物/赋予/牌库标记/攻击走位
  与 A 前逐条对照一致（`[EffectFx]/[GrantFx]/[HealFx]/[Film]` 条数/参数）；
- 战报行顺序与终局 `MatchLogService.ExportMarkdownText` 一致；
- `Tools/验证/战斗回放` PASS=6/0；`rg 'DeferOrRun|ReleaseUpTo|DrainDeferred'` 源文件零命中
  （AOT 旧引用不在此列）；
- 无看门狗/空引用。

**风险与回退**：最大风险是 LiveData 的节拍/HP 冻结口径。回退 = 单提交 `git revert`；A 独立于 B/C。

### B — 联机数据面：`EventFeed.FxOnly` + `MatchLogFull=137`（协议 v18）

**目标**：人类/观战有“演出所需的逐事件数据”，且终局拿到无遮蔽全量行；带宽保持 C 案的收益。

**改动**
1. `NetTransports`：`INetChannel.WantsEvents` 替换为 `EventFeed EventFeed { get; set; }`（枚举见 §1.2）。
2. `NetBattleChannel.StartMatch`：
   - 椅位：`chair.EventFeed = chair.IsAi ? EventFeed.Full : EventFeed.FxOnly;`
   - 观战：`spec.EventFeed = EventFeed.FxOnly;`（**从 false 改为 FxOnly**——这是观战演出的数据前提）
   - 删除 `ForceEventsForTests` 测试钩子（B 后事件流对所有端都有定义；验证器改断言行流+FX 子集）。
3. `NetBattleChannel.FlushDownlink` 事件段：按 `member.EventFeed` 过滤：

| 类别 | 白名单事件 |
|---|---|
| 帧切分 | `StackResolutionStartEvent`、`StackResolutionEndEvent`、`StackEmptyEvent` |
| 伤害/治疗 | `AtomicDamageEvent`、`CombatDamageEvent`、`HealEvent`、`LifeChangeEvent` |
| 死亡/入场 | `CardDestroyEvent`、`CardPutToBattlefieldEvent` |
| 属性/状态 | `CounterChangedEvent`、`StatModifyEvent`、`StatSetEvent`、`KeywordEvent`、`FreezeEvent` |
| 战斗/拼点/运势 | `AttackDeclarationEvent`、`AttackResolvedEvent`、`BlockDeclarationEvent`、`ClashResolvedEvent`、`LuckRolledEvent` |
| 效果视觉 | `EffectFlightEvent`、`FatigueEvent`、`ElementPoolPayEvent` |
| 骨架 | `TurnStartEvent`、`PhaseStartEvent` |

   `FxOnly` 只放行白名单；`Full` 原样；`None` 不发。
4. 全量行通道：
   - `NetBattleChannel` 为每个座位维护 `_logFullHistory[seat]`（`MatchLogLineStream(isSelf=seat,
     redactEffectSummary:false, redactHidden:false)`），与遮蔽行同点渲染（`InstallLogStreams` 同处）；
   - 终局 `OnGameOver` 置 pending，下一次 `FlushDownlink` 末尾发 `MatchLogFull=137`
     （载荷 `MsgNetLogBatch`；AI 填位局也发；观战发 seat -1 全量）；
   - `NetGameClient.OnLogFull`；`RefreshMemoryPackOrder` 登记 `MMLF_Lines`；`Version=18`。
5. `NetProtocolLoopbackVerifier`：
   - 删测试钩子，改为：人类/观战收到 `FxOnly`（`StackResolutionEnd` 计数>0、`CardDestroy` 等白名单事件到）；
   - 新断言 `MatchLogFull` 到达、全量行比遮蔽行多（R1/R2 行替换）、`EventId` 对齐；
   - 行流/事件流/快照三路不死锁（socket 整局）。

**验收**
- 编译 0；`TideServer verify --sections V11` 全绿；Unity `NetProtocolLoopbackVerifier` 全绿；
- 联机一局：人类下行 = 行流 + FxOnly（字节 ≤ 全量事件 50%）；终局收到 `MatchLogFull`；
- 观战同局：行流（-1 全量）+ FxOnly 事件 + fullInfo 快照；
- 本地局不受影响（`redactHidden:false`）。

### C — `NetFilmSource`：联机帧生产 + 联机/观战播放器 + 录制

**目标**：联机对战/观战与本地同一播放器、同一演出执行器；终局自动留一条可复盘剧本。

**改动**
1. 新增 `Battle/Playback/NetFilmSource.cs`：
   - `OnEventBatch(MsgNetEventBatch)`：按 `StackResolutionEnd` 切步、`StackEmpty`→RoundEnd；
     每帧 `LastEventId`=本批最后事件；`PreOps/Ops` 由 `NetFxMapper` 把 `NetEvent` 映射为 `BattleFxOp`
     （字段从现有 `NetParam` 读：Entity→Rid/Seat/CardId、Enum→IntValue；缺省字段按表现层可缺省）；
   - `OnLogLines(NetLogLine[])`：`MatchLogLine`→`BattleLogLine`，按 `EventId` 归帧（行可能晚于帧到，
     存 pending 列表，帧落地时合并）；
   - `OnSnapshot(MsgGameStateSync)`：`BattleView.BuildNet` → `View` 帧（首帧 #0）；
   - `Tick`/`Enqueue`：帧攒到 N 或结算边界后投 `BattlePlayhead.Enqueue`（LiveData）；
   - 录制：每帧进 `BattleFilm`（Header：ViewerSeat、双方名、matchId）；
   - 终局触发：`NetLogLine.Flags.GameOver`（行流旗标）或 `RoomState.Finished` 二者先到即
     `BattleFilmStore.Save`（遮蔽版）；`MatchLogFull` 到达后按 `EventId` 回填 `FullText` 重写；
     断线/未收到全量时保留遮蔽版（已知限制）。
2. `BattleScreen.Net`：
   - 去掉 `NetOnEvents/NetOnLogLines/NetOnSnapshot` 的直接 UI 写入，改为投 `NetFilmSource`；
   - `StartNetFan` 创建 `NetFilmSource` + `BattlePlayhead`（LiveData）+ 战斗屏 `IBattleStageSink`
     （视图/执行器/Combat/视觉门；与回放同实现）；
   - `_log.ResetForNetMatch` 保留；`NetOnMatchSummary` 的 `EncounterRecord.matchId` 用本局 id；
   - 交互数据（`_netSnapshot`/计时/选目标）仍在收到时立即更新，只有“渲染+行+演出”按帧走；
   - 积压 >6 帧压缩停顿（`BattlePlayhead` LiveData 已有节拍参数）。
3. 观战：同一路径（`viewerSeat=-1`），不录制 film。
4. `NetFxMapper` 放 `Playback/`，与 `NetLogRenderer` 无依赖（后者已删）。

**验收**
- 编译 0；`NetProtocolLoopbackVerifier` 全绿；
- 大厅 AI 填位房 + 双真人房各 1 局：战报按帧出现、有伤害/回复/死亡/入场/攻击演出；
- 观战同局：画面/战报与玩家端同帧推进（允许视角差异）；
- 终局 `Films/<matchId>.film.gz` 存在（人类座位记录者）；
- 无 NRE/看门狗；人类下行字节达标。
