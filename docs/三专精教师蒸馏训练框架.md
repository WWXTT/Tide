# 三专精 → 教师 → 蒸馏学生：训练框架（计划）

> **状态：计划（未实现）**。本文只定义流程、口径、产物与验收点；不含代码改动，也不代表已经执行。
> 日期：2026-11-25。
> 关联：原《回到一期训练目标》（已删除；事实见 AI训练说明 附 A.1）、[一期训练_期望与验收](一期训练_期望与验收.md)、[AI训练说明](AI训练说明.md) §0/§3.4、[预组改造方案](预组改造方案.md) §1.3、[计价与塑形_统一口径](计价与塑形_统一口径.md)。
> 一句话：**三套预组各自专精训练；只有达到教师门槛的专精才当教师；教师只用于蒸馏/DAgger，最终交付一个学生网络（不是三网络 + 硬路由）。**

---

## 0. 为什么做这个框架

1. 共享网络三套互相干扰：绿的长链（沃土铺场 → 献满 11 地 → 归根回 15 张 → 重铺 11 地 → 14 费阿格洛斯）在红/蓝的梯度里被稀释。计划起点（599k）的共享 run 绿镜仍是 0/48、vs 红 0/48、T5 大哥 0；复核时 run 已 665k，648960 评估 median 转正 +0.46pp（见 §5）。
2. 直接“三份工程 + 最后硬路由”不满足一期契约的“**同一个网络执三套**”，也不满足二期“拿到什么都会玩”：新卡组没有专家可路由。
3. 本框架把“隔离变量”和“最终交付”分开：
   - **训练期**：三专精隔离干扰，谁达标谁当教师；
   - **交付期**：蒸馏成一个学生网络，部署/ONNX/评估仍是单模型；
   - **二期**：教师只当训练期脚手架，学生在多样卡组/自对弈/人类日志上继续学。

## 1. 目标与非目标

### 1.1 目标

1. 红/绿/蓝各有一个专精 checkpoint；在它自己的 **6 格**（3 对手 × 2 座位）达到教师门槛。
2. 用达标教师做离线 BC + DAgger/蒸馏，训一个学生网络。
3. 学生通过一期 18 格认证：17 个常规格逐格 Δ ≥ 0、中位数 ≥ +15pp、饱和格不退步（当前口径见[一期训练_期望与验收](一期训练_期望与验收.md) §2·VI）。
4. 学生是**一个网络**；部署、ONNX、评估、认证路径不变；不引入硬路由、不写卡组 key 表。
5. 框架可扩展到二期：新卡组加专精/教师只作为训练期课程，学生继续在多样卡组上训。

### 1.2 非目标

- 不把“三份工程 + 硬路由”作为最终架构。
- 不按卡组写 key 掩码、绿线专用奖励；专精训练也不改环境。
- 不把教师当最终产物；教师只在训练/蒸馏期存在。
- 不追求三专精各跑满 2M；短跑 + 门槛 + 早停。
- 不在本计划里改观测/动作/塑形/判据；这些是冻结项，见 §3。

## 2. 角色与定义

| 角色 | 定义 | 产物 |
|---|---|---|
| **专精（Specialist）** | 只训练一套预组（`--model-theme red/green/blue`）的策略网络，对手仍是脚本三套 | 一个 run 目录 + `last/best` |
| **教师（Teacher）** | 通过教师门槛的专精 checkpoint；冻结权重，只用于给学生的状态打标签 | `teacher_manifest.json` + 冻结 `params.msgpack` |
| **学生（Student）** | 一个网络，吃三套预组的状态，学习三个教师的策略/价值；最终交付物 | 一个 run 目录 + ONNX |
| **教师门槛（Teacher Gate）** | 专精在自己 6 格上的胜率门 + 绿行为门（见 §8） | `teacher_gate.json` |
| **蒸馏（Distillation）** | 教师分布/价值 → 学生；先离线 BC，再 DAgger；可选 PPO 微调 + 教师 KL 锚 | `distill/round_*/` |
| **教师路由（仅训练期）** | 训练 harness 按 `info.modelTheme` 选择对应教师；学生只吃观测，不吃路由 | 训练代码内部 |

**关键区别**：教师路由只存在于训练/蒸馏期；最终学生是一个网络，部署时没有路由。

## 6. Stage 1：绿专精试点（先跑最难的）

### 6.1 目的

区分两种假设：

- **H1 共享干扰**：三套挤一个网络，绿的梯度被红/蓝稀释；单跑绿应明显抬头。
- **H2 组合执行机制**：11 步逐目标选择 + 延迟回报，专精也学不会；单跑绿不会抬头。

只有 H1 成立，三专精才值得全量跑；H2 成立则先修通用机制（option / effect-completion），不要浪费三份训练。

### 6.2 配置

- 模型侧：`--model-theme green`
- 对手：`--opponent simpleai`（三套脚本）
- 评估：`--eval-model-theme green`（训练内只评绿 6 格；别套不评）
- 热启动：从共享 `last`（`--init-params .../last/params.msgpack`）——**已定**；from scratch 只作为“热启动不抬头”时的诊断对照，不作为并行分支。
- 预算：先跑到 300k 作为试点门（约 6 小时）；抬头则**同一 run 继续到 800k**；不抬头停（无 resume，杀掉即止）。
- 评估节奏：每 50k 评一次（48 局/对，只评绿 6 格，仅看趋势）。
- 产物：`logs/tide_ppo_simpleai_green_teacher__42__<ts>/`

### 6.3 观察指标

| 指标 | 当前共享基线 | 试点目标（初值，待实测） |
|---|---:|---:|
| 绿镜 P1（vs 脚本绿） | 0/19 | ≥ 30% |
| 绿镜 P2 | 0/29 | ≥ 10% |
| 绿 vs 红 P1/P2 | 0/48 | P1 ≥ 15%、P2 ≥ 10% |
| T5 阿格洛斯率（全局 ≤10 回合） | 0 | ≥ 10% |
| 牺牲→回收链率 | 13.5% | ≥ 30% |
| 每次牺牲目标数（满献 11） | 粗算 ~6 | 出现 ≥10 的局 |

> 表中共享读数取自 549120 的 18 格矩阵；599040 评估 selector 仍 −0.600、median −2.5pp，绿格未见变化。
> “粗算 ~6”来自 `green.sacrifice_rows / model_behavior.sac`，两个统计窗口不同，只作方向；试点里必须在同一局打点确认。

### 6.4 决策门

- **抬头**（任一硬指标明显改善，且绿镜 P1 ≥30% 或 T5 大哥 ≥10%）→ 同一绿 run 继续到 800k；同时启动红/蓝（Stage 2）。
- **不抬头** → 停；先做通用组合执行修复（见 §9.3 的 option/effect-completion 备选），不跑红/蓝专精。
- **热启动不抬头、from scratch 抬头** → 后续专精改用 from scratch（诊断分支）；记录对照。否则默认热启动。

### 6.5 产物

- `green_pilot/` run 目录
- `green_pilot_funnel.json`（5 个数：到 T5 局数、T5 时沃土+归根在手/地数、牺牲目标数直方图、归根回收张数、重铺地数/14 费/大哥落地）

## 8. Stage 3：教师门槛（Teacher Gate）

> 教师门是**蒸馏源质量门**，不是最终验收；学生仍要过 18 格认证。
> 教师门按“本套 6 格”判，不要求 18 格。

### 8.1 胜率门

对每个 deck `d`，6 格 = `(d, opp, seat)`，`opp ∈ {red, green, blue}`，`seat ∈ {P1, P2}`。

**T1（可当教师的最低线）**

- 常规格：每个格 Δ = 模型胜率 − 同格脚本基线 ≥ 0（点估计）；95% 区间跨 0 的格先加测，不直接判过。
- 饱和格：按不退步判，`wr ≥ 基线 − 5pp`（当前只有绿镜 P1，基线 96.5% → ≥91.5%）。
- 6 格等权聚合：`Δ_agg = mean(6 格胜率) − mean(6 格基线) ≥ +5pp`。
- 终评：200 局/座位（`eval_matrix.py --episodes 400`，3 对手 × 400 = 1200 局）。

**T2（推荐教师线）**

- 常规格：每格 Δ ≥ +5pp（点估计）。
- 饱和格：不退步。
- `Δ_agg ≥ +10pp`。
- 终评：同上 200 局/座位；跨评估点稳定（连续 2 次达标）。

> **T1/T2 轮换（2026-11-25 用户定）**：T1 是教师最低线，T2 是推荐线；不要求所有 deck 都到 T2。蒸馏按轮次轮换 T1/T2（见 §9.6）：T2 轮次用 T2 教师，某套没有 T2 就用它的 T1 顶上并在 manifest 记 `tier_used`。只用 T1 的教师仍可进蒸馏，标记 `teacher_tier=T1`；学生若差最后几个 pp，优先补 T2 教师或加 DAgger，不靠放宽判据。

### 8.2 绿行为门（仅绿教师）

绿是长链卡组，胜率可能来自非目标打法；教师必须展示目标线，否则蒸馏会把坏习惯教给学生。

| 行为 | 口径 | 阈值（已定，不改） |
|---|---|---:|
| T5 阿格洛斯 | 作为卡打出（非地落），全局回合 ≤10 | ≥ 20% 绿局 |
| 牺牲→回收链 | `mChain=1`（先牺牲后归根） | ≥ 50% 绿局 |
| 满献 | 单次牺牲目标数 ≥11 | ≥ 30% 绿局（或 ≥50% 的 T5 局） |
| 沃土打出 | 作为卡打出（非地落） | ≥ 1.5 次/绿局 |

- 口径来自 `TideHeadlessDriver.TrackModelBehavior` 的 `mSac/mRec/mChain/mAgros`（Apply 成功才计）与行为探针；阿格洛斯/归根“当地落”不算召唤/回收。
- 阈值按上表固定（2026-11-25 用户定“行为门阈不变”）；脚本绿同协议跑 20–50 局只做对照，对照结果写进 `teacher_behavior.json`，不改阈值。
- 红/蓝暂不设行为门（胜率门即可）；后续如需可加（红法术线/蓝控制线）。

### 8.3 统计口径与工具

- 筛查：`--episodes 200`（100/座位/格，Wilson 半宽约 ±10pp）；终评：`--episodes 400`（200/座位/格，约 ±7pp）。
- 同 `--seed 20261122`，与 `eval_matrix.py` v2 配对协议一致；不同执行器不可跨引基线。
- `certify_phase1.py` 的 `judge()` 期望 18 格，不能直接给 6 格专精出证；新建小工具 `teacher_gate.py`：
  - 读 `matrix_eval_teacher.json`；
  - 复用 `phase1_criterion` 的 `SCRIPT_MATRIX_BASELINES`、`is_saturated`、`delta_ci`、`wilson_interval`；
  - 逐格 verdict（pass / needs_more / fail / saturated_pass / saturated_fail）；
  - 算 `Δ_agg`、`T1/T2`、`needs_more`、`tier`；
  - 读 `teacher_behavior.json` 合并绿行为门；
  - 输出 `teacher_gate.json` 与退出码（0=T2、1=T1、2=不合格）。
- 工具不改判据常量；只做“6 格子集 + 教师门”的薄封装。

### 8.5 不合格处理

- T1 未过：延长 100k 再测；仍不过 → 该 deck 没有教师，**不蒸馏**；先查是 H2（组合机制）还是教师训练不足，带数据找用户拍板。
- 绿行为门未过但胜率过：标记 `teacher_tier=win-only`；不推荐直接蒸馏；先补行为（更多教师步数/课程），或明确接受“蒸馏胜率打法”的风险。
- 不为凑教师门放宽判据；不把 `needs_more` 当 pass。

## 9. Stage 4：蒸馏

### 9.1 两种方式

| 方式 | 做法 | 作用 | 取舍 |
|---|---|---|---|
| **4a 离线 BC（可选）** | 教师跑 N 局/套，存 obs + 动作表 + 教师分布/价值；学生做 KL/CE | 给学生一个好初始化 | 有协变量偏移；存储动作表较重 |
| **4b DAgger（必须）** | 学生自己跑，教师在学生访问的状态上打标签；学生学教师分布 | 纠偏；覆盖学生自己的状态分布 | 需要教师在线前向；实现比 BC 复杂 |

推荐：**4a 可选、4b 必须**。若时间紧，直接 4b；4a 只作为加速初始化。

### 9.2 教师路由（仅训练期）

- 训练 harness 每局从 `info.modelTheme` 知道学生当前执哪套；据此加载对应教师。
- 教师和学生看**同一份观测/同一张合法动作表**；教师只提供分布/价值，不执行动作。
- 学生观测里已有 `g[88..95]` 牌库标签 + 完整牌库块；**不额外喂 deck id**，不训练硬路由。
- 部署时只加载学生；教师不存在。
- **RNN 口径（2026-11-26 登记，实现见 `distill_student.py` collect）**：DAgger 采集时教师的
  `rstate` 沿**学生轨迹**推进（学生选动作 → 喂回下一步），教师 logits 是「教师在看学生历史」，
  不是「教师走自己的轨迹」。这是 RNN-DAgger 的常规近似，但消费教师分布时要按此解读——
  pos 上的教师价值也同受此影响；如需纯教师分布，用 `--actor teacher`（BC 4a）自走自标。

### 9.3 蒸馏损失

基础损失（逐决策步）：

```
L = α * KL( π_teacher(·|s) || π_student(·|s) )
  + β * ( V_student(s) − V_teacher(s) )²
  + γ * L_aux（可选：终局胜负 BCE / 熵正则）
```

- 温度：教师分布用 τ=1–2 软化；学生同温度；推理时 τ=1。
- mask：只对合法行动行算 KL（动作表 `[0]valid`）；非法行不参与。
- 价值：教师 critic 的价值作为回归目标；教师价值也只用于训练期。
- 权重初值：`α=1.0, β=0.5, γ=0`；按验证集调，不按训练 loss 调。
- 可选 PPO 微调（见 §9.7）：在 PPO loss 上加 `λ_t * KL(π_teacher || π_student)` 作为**教师 KL 锚**，防止三套互相遗忘；λ_t 退火到 0。

### 9.4 数据配比

- 每轮：每套 100–200 局；对手三套脚本各 1/3；座位 50/50。
- 每轮教师 tier 按 §9.6 轮换；同一轮内三套等权。
- 三套等权；不按当前胜率加权（避免强者恒强）。
- 状态来源：学生自己的 rollout（DAgger）；4a 可混教师 rollout（建议 ≤30%）。
- 存储：每轮一个 shard（obs / action rows / teacher probs / teacher value / deck / seed / step）；放 `distill/round_<n>/`，不进 git。

### 9.5 学生网络

- 第一版：与教师同架构（`channels=128, rnn=512, GRU`），保证可比。
- 初始化：共享 v21 `last` 或 from scratch；两种都跑一次小对照（各 50k 蒸馏步），选验证集更好的。
- 若蒸馏 underfit（教师分布学不像、18 格上不去）：先加宽学生（192/768）再试；仍不行才考虑 MoE/适配器（仍是单模型，不是硬路由）。
- **不平均三个教师的权重**（特征子空间不同，基本不可行）。

### 9.6 轮次与预算

- **4 轮 DAgger**（§16.2 定；3–5 范围内取 4）；每轮 300–600 局（三套合计）；每轮训练 1–2 小时。
- **T1/T2 轮换**（2026-11-25 用户定）：奇数轮用 T1 教师，偶数轮用 T2 教师；某套没有 T2 时该轮用它最高可用 tier（通常 T1），manifest 记 `tier_used`。按奇偶轮落地，若要别的顺序只改这张表：

  | 轮次 | 教师 tier | 缺 tier 回退 |
  |---|---|---|
  | 1 | T1 | T1 |
  | 2 | T2 | T1 |
  | 3 | T1 | T1 |
  | 4 | T2 | T1 |
  | 5 | T1 | T1 |

- 每轮后跑 18 格筛查（`eval_matrix --episodes 200`，100/座位/格）看趋势；不达标不进入下一轮调参，先看逐格。
- 学生 `best` 选点仍用现有 18 格最小 Wilson 下界 Δ；不用训练 loss 选。

### 9.7 学生验收

- `eval_matrix.py --run <student> --split best --episodes 400 --seed 20261122` → 200/座位/格。
- `certify_phase1.py --run <student> --matrix-best ...`：17 常规格 Δ≥0、中位 ≥+15pp、饱和不退步。
- 差 ≤5pp：加 1–2 轮 DAgger，或短 PPO 微调 + 教师 KL 锚；差 >5pp：回到教师门/数据配比，不放宽判据。
- `last` 只报告，不作达标依据。

### 9.8 对照实验（至少跑）

| 对照 | 目的 |
|---|---|
| 共享停点 checkpoint vs 学生 | 证明蒸馏/RL 有净收益 |
| 最好单教师 vs 学生 | 学生不能明显低于最好教师 |
| 学生 BC-only vs BC+DAgger | 证明 DAgger 必要 |
| 学生蒸馏 vs 蒸馏+PPO | PPO 是否值得 |
| 三套逐格 Δ | 确认没有“红蓝换绿”的偏科 |

## 15. 风险与回退

| 风险 | 影响 | 缓解 |
|---|---|---|
| 绿教师过不了饱和格（绿镜 P1 ≥91.5%） | 绿无教师 / 学生也过不了认证 | 这是当前判据的硬点；先看试点能否接近 91.5%，再决定是否向用户提出“饱和格口径重议”；不悄悄放宽 |
| 教师只对脚本过拟合 | 学生/二期弱 | 教师门加行为门（绿）；二期多样对手/人类日志 |
| 教师弱 → 蒸馏天花板低 | 学生上不去 | T2 优先；T1 只当过渡；差 >5pp 回去补教师 |
| T1/T2 轮换时某套缺 T2 | 该轮教师质量不一致 | 回退到该套最高可用 tier，manifest 记 `tier_used`；逐轮看逐格，不混轮比较 |
| 学生容量不够（三套挤一个网络） | 蒸馏 underfit | 先加宽学生；再试 MoE/适配器（仍是单模型）；不回到硬路由 |
| DAgger 状态分布偏移 | 学生学不会教师 | 4b 必须；4a 只做初始化；每轮重采学生状态 |
| 蒸馏后 PPO 微调遗忘 | 某套掉回去 | 教师 KL 锚 + 短微调 + 逐格监控 |
| 三份副本漂移 | 结果不可比/认证失败 | 三份同一冻结快照 + 逐文件 SHA256；每份 preflight；任一漂移即停 |
| 三开抢 CPU/GPU/Library | sps 掉、OOM、锁冲突 | 三份独立 Library/Logs；`XLA_PYTHON_CLIENT_MEM_FRACTION=0.33`；前 10k 步测 sps；<8 sps 回退 2+1 |
| 并行启动后跑 preflight 误报 | 启动被拒/假红灯 | 三份先 preflight；绿先启动，红/蓝用同一批快照后续启动；启动后不重跑；复检用 `--gate-only` |
| `needs_more` 被当 pass | 假达标 | 教师门/学生认证都先加测；不跨 0 才判 |
| 学生“偏科”（红蓝换绿） | 中位数过、单格不过 | 逐格 Δ 表；best 选点用最小 Wilson 下界 |

**回退**

- 学生不达标：回退到共享停点 checkpoint 或最好单教师；教师权重冻结保留。
- 教师不达标：不蒸馏；延长/修机制；不把教师门降到 T1 以下。
- 蒸馏工具出问题：先 BC-only 出基线，再补 DAgger；不跳过认证。

## 16. 已定 / 推荐默认

### 16.1 已定（2026-11-25 用户）

1. **教师门 T1/T2 轮换**：T1 = 常规格 Δ≥0 + 聚合 +5pp；T2 = 每格 +5pp + 聚合 +10pp；蒸馏按 §9.6 奇偶轮轮换，不要求所有 deck 到 T2。
2. **绿行为门阈值不变**：按 §8.2 表固定（T5 大哥 ≥20%、链 ≥50%、满献 ≥30%、沃土 ≥1.5 次/局），不因对照改阈值。
3. **热启动**：三专精都从共享 `last` 热启动；from scratch 只作诊断对照。
4. **并行**：三份同快照副本并行；三份先各跑 preflight（无训练时），先启动绿试点，红/蓝用同一批快照后续启动；独立 Library/Logs，端口自动分配（§3/§7.1）。

### 16.2 推荐默认（2026-11-25 用户授权“剩下的你推荐”，按此执行）

1. **绿镜饱和格**：**先按 ≥91.5% 不退步执行**，不提前放宽。触发复拍条件：绿专精训练到预算上限（T1 已达标但绿镜 P1 仍 <80%）且 T5 行为门已过，带数据找用户重议该格口径（契约变更）；若行为门也没过，先修组合机制，不谈口径。重议时我的推荐：把绿镜 P1 饱和格改成“绿镜 P1+P2 聚合”或“绿 vs 红/蓝双座 + 行为门”，其它 17 格不动；这是契约变更，必须你签字。
2. **学生初始化/宽度**：从共享 `last` 热启动；第一版同宽（`channels=128, rnn=512, GRU`）。若蒸馏明显 underfit（教师分布学不像、18 格差 >5pp），再加宽到 `192/768`；不从 scratch 起（只保留诊断对照）。
3. **蒸馏方式**：4a 离线 BC 50–100 局/套做初始化；4b DAgger **4 轮**、150 局/套/轮；损失 `KL(τ=2) + 0.5 × 价值 MSE`，mask 非法行。PPO 微调只在学生距认证 ≤5pp 时做，加教师 KL 锚（λ 从 0.1 退火到 0）；差 >5pp 先回教师门/数据，不靠微调硬拉。
4. **预算**：绿试点 300k；红/蓝 600k、绿 800k 上限；T1 具备教师资格，继续尝试 T2 到上限；蒸馏 4 轮；学生认证 400 局/对（200/座/格）。并行三开若每 run <8 sps，按 §7.1 回退 2+1/顺序。

> 除第 1 条的“触发复拍”外，其余按上表执行；中途要改再拍板。
