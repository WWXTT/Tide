## 建卡规范（本池专用）

- 效果条目 schema：`EffectSlimDto`（`Assets/Scripts/HotUpdate/CardCore/Effects/EffectSlim.cs`）。
- 原子 refId 一律指向现行原子表五分文件 ID（2026-11-02 快照）；`Tools/重推导测试卡表费用与ID` 悬空守卫会拒绝任何漂移 ID。
- 引擎挂法：`steps[0].atom.branch = {settle:3, engine:N, engineParam:x, then:[奖励原子]}`；engine 序 1倒计时/2运势/3拼点/4死亡计数/5元素充盈/6诅咒/7祝福/8团结。
- 光环挂法：结界登场效果 `steps[0].atom = {refId:光环行, str:规则短名, value:作用面}`；作用面 0己方/1双方/2对方；str 用 `RuleAuraComponents` 常量短名（表 EffectType 未翻新期间必须带）。
- 关键词挂法：生物印刷 `keywords:["FirstStrike",...]`（运行时 id 见 `GrantKeywordHandlerFactory.Specs`；帷幕=Taunt、剧毒=Venom、无实体=Spellban、狩猎=Hunt；苏醒 Awaken 已随 2026-11-02 机制删除）。
- 抉择=法术多行主动（effectIds 挂多条 timing19/activation2 条目，打出时选行）；`StepRef kind=2 choices` 无存量实例且合成器只读，不用。
- 落盘 ID 全部占位（卡 `C_t000NNNN` / 效果 `t000NNNN`），跑重推工具后自动换内容哈希并跟换卡内引用。
- 占位卡 costList 恒 `[0,0,0,0]`（4 位灰红蓝绿），费用由 `RegenOneDeck → CardCostService.Derive` 推导；曲线轴设计按原子表锚价预算，最终档位以工具日志为准。
