## 填表口径

- **自产原创（FL Studio）**：来源填 `自产（flstudio-mcp 会话 <日期>）`，作者填项目名，许可填 `原创自有（FL Studio
  授权范围内）`；工程文件（.flp）归档路径一并写入「处理命令」列。
- **外部素材**（备选路线）：来源 URL + 逐条许可证据（截图存 `.ztmp/audio/license/`）；免费层禁商用者不得入库。
- **sha256**：PowerShell `Get-FileHash -Algorithm SHA256 <文件>`。
- **试听结论**：BGM 记「循环 3 次接缝无咔哒 + loop 点（分:秒）」；SFX 记「短/不刺耳/同帧叠爆测试」。
