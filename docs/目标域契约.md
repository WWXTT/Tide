# 目标域契约（Target Domain Contract）

> 单一规范：目标/参照的域声明、解析分层与选择权归属。原 P0 契约仅存在于讨论，本文件为
> 2026-11-08 目标选择重构（选择从 handler 搬回数据）随批落档的首个入库版本。
> 实现单源：`CardCore.TargetAxisRules`（文法/收窄）· `CardCore.Attribute.EffectHandlerRegistry`（spec 计划）·
> `CardCore.TargetFilterSystem.TargetResolver`（过滤分层）。

## 1. 文法

```
domain   := selector (";" selector)*
selector := region (":" category)*
```

- 中文书写；全角/半角分号兼容；空格容忍（`对方战场:生物; 对方角色`）。
- region：自己 + 3 侧（己方/对方/双方）× 6 区（战场/手牌/牌库/墓地/除外/场地）+ 角色位（`己方角色/对方角色/双方角色`——**角色=区域**，不是类别）。
- category：生物 / 结界 / 法术 / 卡（印刷位；多类别顿号并列）。
- 「对方」= 席位抽象（四人局改 OpponentsOf 单点），不是战场简写。

## 2. 角色：受体域 vs 参照域（2026-11-08 定案）

| 列 | 角色 | 例（活体炸弹 `2cca9b23`） | 运行时去向 |
|---|---|---|---|
| `Domain` | **受体域**（被作用对象） | `对方战场:生物; 对方角色` | `context.Targets` |
| `RefDomain` | **参照域**（数值基准锚，复用同文法） | `己方战场:生物` | `context.Refs["ref"]` |
| `RefPick` | 参照收集时机：`Cast`（声明期选，取消=撤销发动）/ `Resolve`（结算期问）/ `Auto`（不弹窗） | `Cast` | spec 计划分派 |
| `RefRequired` | 参照候选为空是否空转（v1 恒 true；false 留扩展位） | `true` | 装载校验 |

- `RefDomain` 与 `Domain` **各自独立产轴**——不再用 `entry.kinds` 顶替参照域；converter 对 `RefDomain` 非空的行忽略 `entry.kinds` 作为域源（kinds 仍照旧填 `TargetKinds` 供 SideLock/隐藏区等区级消费口）。
- 旧「收窄后空 selector 挂 null → 外层 {target} 回落 kinds 选参照」特例已删（2026-11-08）：非法收窄=空轴无候选，错误可见不静默回落。

## 3. 解析分层（参照与受体的过滤差异——铁律）

| 校验链 | 受体（Targets） | 参照（Refs） |
|---|---|---|
| 可见性（潜行/隐藏区/对方手牌隐藏） | ✅ `ExcludeUnselectable` | ✅ 同款（不能「看穿」潜行） |
| 可指性（帷幕/守护/edict 豁免） | ✅ `ApplyTauntRestriction` | ❌ 跳过（参照不是被施加效果的对象） |
| `OnTargeted` 等被指定事件 | ✅ 发 | ❌ 不发（否则选参照会触发对方触发式） |
| 声明期外给目标硬校验 | ✅ `FilterPreselectedTargets` | ❌ 不经此口（参照不进 Targets） |

任何「参照也走同一条 `ResolveTargetsInteractiveAsync`」的实现都是错误的——参照候选解析单源
`EffectHandlerRegistry.ResolveReferenceCandidates`。

## 4. spec 计划（选择权声明）

`CollectSpecPlan(def, ctx)`（声明期收集器 / 结算解析 / LAE / SimpleAI 四方单源）：

1. **Reference spec** 前置：每个 `RefDomain` 原子一个（`AiMode=Enumerate`——参照是唯一有意义的决策维度）；
2. **Target spec**：非分段交互原子按**同受体域分组共享**（同域并列原子→单 spec 单窗同目标；跨域并列→各自 spec）；
3. **分段受体 spec** 尾置（`AiMode=Auto`——LAE 不展开，引擎/AiOrder 代选；**Auto ≠ 取首**，打脸/排序照策略）。

- 顺序固定 Reference→Target（人类窗口序）；**绝不做 N 参照 × M 受体笛卡尔积**（§坑③）。
- `SpecKey = atom:{i}/spec:{j}/role:{r}`（effect 级共享组用 `effect/spec:{j}/role:target`）——网络/重放/触发重入/AI 代选按它对齐，**禁止用「本效果第几次弹窗」隐含序号**。
- 预选队列按 spec 归属有序消费：参照吃声明期预选，受体不吃参照的队（跨 spec 不互抢）。

## 5. handler 铁律

`IAtomicEffectHandler.ExecuteAsync` 内**禁止**发起任何目标选择（`TargetSelectionService.RequestAsync` /
`CellSelectionService` / 弹窗 / 网络选择入口）。守卫：引擎调 handler 前挂 `BeginHandlerScope(context)`，
作用域内 `SpecKey ∉ context.ApprovedSpecKeys` 的请求 → `TideLog.Error` 点名（先叫后清零）。
已登记通用化债务（非参照族、不阻塞验收）：RedirectTarget / DiscardCard / Sacrifice / DiscoverCard / MoveUnit。

## 6. 冻结硬规则（沿承 P0 定案）

- **冻结无元素池**：双方战场:生物 等面积域不含元素池地牌（地牌=元素池区域 selector 显式声明才可达）。
- 增加新域表达**只扩文法表**（TargetAxisRules 词表），不改 handler；新选择行为**只进 spec 计划**，不进 handler。
- `TargetFilter`（属性 token：Damaged/Tapped/…）只作用于受体轴；参照轴不挂属性 Filter（参照只做可见性过滤）。
- 训练身份哈希（`CardIdentityService`）不含 `RefDomain/RefPick/RefRequired/valueExpr/valueMax`——表列与
  动态值字段是平衡层/行为层可变量，不换训练身份（内容指纹经 `ContentHasher`/`NetMatchHandshake.RowSig` 拦截内容漂移）。

## 7. 动态数值（2026-11-08 步6）

效果条目（`AtomicEffectEntry`）：`value`（名义锚，计价/描述读它）+ `valueMax`（静态上界，只告警不拦、
**不参与计价**）+ `valueExpr`（白名单 `ref.power|ref.life|ref.cost`——结算期经
`EffectExecutionContext.ResolveValue` 读 `context.Ref` 活值；空=旧路径 `GetRolledValue` 名义值±幅度掷）。
执行顺序钉死：解析 bindings（Refs）→ `ResolveValue` → 增/减伤修正链 → 按幅度掷 → 逐目标结算。
