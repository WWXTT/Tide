## 1. 结论先行

改 **两层、零引擎改动**：

- **表现层**：地牌行 4 格"视觉合并"为一条长条，每张地牌一张平铺面片（与生物横置卡背同尺寸），长条一端留一截显示 `填充/上限`；左下万能格拆成 5 分格显示灰红蓝绿彩临时元素数量，费用粒子全部从该格发出。
- **交互层**：手牌**废除 Use/Place 按钮**改为拖拽；拖拽落点三分（战场=发动、地牌长条=放地、边缘装饰=取消），法术无箭头且不指定释放位置；地牌改"3D 射线点面片即横置产色"。

**不改的东西（关键）**：4 个地牌格坐标、落格、横置/付费规则、视图数据结构、悬停/Information/网络快照/教学闸——全保留。因为引擎、悬停、快照、AI、教学共有 10 处以上依赖"地牌=4 个格坐标"。

## 4. 模块设计

### 4.1 地牌长条（需求 1 / 3）

#### 4.1.1 面片规格（与生物横置卡背同规格）

| 参数 | 值 | 来源 |
|---|---|---|
| 面片宽 | `0.55`（世界单位） | `UnitCardPlate.Width` |
| 面片高（竖版长边，沿 Z） | `0.55 × 512/344 ≈ 0.819` | `UnitCardPlate.CardAspect` |
| 贴地抬升 | `0.012` | `UnitCardPlate.LiftY` |
| 可用姿态 | 竖版平贴：`Quaternion.Euler(90, 0, 0)` | `UnitCardPlate.Portrait` |
| 横置姿态 | 原地绕 Y 旋 90°：`Quaternion.Euler(90, 90, 0)`（占 X 0.819 × Z 0.55） | `UnitCardPlate.Landscape` |
| 转向时长 | `0.12s` slerp（0 = 瞬切） | `UnitCardPlate.TurnTime` |
| 材质 | 按锁定色着色（`UiStyle.ManaBlock{Gray/Red/Blue/Green}`），可叠加元素图标 | 与描边环同源色 |

> 面片本体默认 = `Element.prefab` 同管线（Quad，与 `UnitCardPlate`、假影、瞄准面片同模板），
> 新增 `LandCardQuad.prefab` 仅作为**可换美术的实例化源**（多一个 BoxCollider 与可选 TMP/图标子件）。

#### 4.1.2 长条底板

- 在 `BattleStage.prefab` 的 `Board` 下烘焙 `land-strip-self` / `land-strip-opp`：
  位置覆盖地牌行 4 格顶面（x2..x5），y = 0.010~0.012（低于面片 0.012，高于地块顶面 0），
  长度 = 4 × 格距 ≈ 7.62m，宽度 ≈ 0.9m；右端（靠 `tile-6-0` 卡组侧）留 0.72m 数字段。
- 代码只按名绑定、控制显隐与高亮，**不在 UGUI 层拼节点**（符合"UI 只绑定不生成"）。
- 底板透明/半透，让下方六边形格缝仍然可见；若希望"完全合并"，把底板设为不透明深色条即可，
  4 格 tile 的 mesh 仍保留（承担射线/按压/落格高亮）。

#### 4.1.3 面片排布算法（`LandStripFx.Reconcile`）

```
stripW   = 4 × (InnerRadius × 2) ≈ 7.62
capW     = 0.72                 // 右端数字段（靠卡组侧）
usable   = stripW - capW ≈ 6.90 // 左段=面片区
n        = pooled.Count
w        = 0.55                 // 固定 = UnitCardPlate.Width（用户定稿）
pitch    = Clamp(usable / max(n,1), w, 0.62)   // 间距：最多 0.62（0.07 缝），极多时压缩到面片宽
start    = faceLeft + (usable - pitch*n) * 0.5 // 整组在面片区内居中
x_i      = start + pitch*(i + 0.5)
z        = 地牌行中心（z=0 行，格心）
y        = 0.012 + (横置张数分层 * 0.0015)     // 横置占位变宽，防叠面闪
横置      : 绕 Y 90°（0.12s slerp）+ 压暗 0.55 + 角标
锁定色    : 面片底色 + 小元素图标（复用 BattleTileFx.ElemMaterial 同一资产）
```

- 上限封顶 10 张：`n ≤ 10` 时单行完全放得下（10 × 0.62 = 6.2 < 6.9），**不压缩、不重叠**；
  横置后单张占宽 0.819，10 张全横置会相互覆盖约 0.2m —— 允许覆盖（卡堆观感），按各自 y 微抬分层。
- 若未来上限 > 11：`pitch` 触底到 0.55 后开始允许重叠（后放入的渲染置顶）。
- 引擎池序 = 放入顺序，面片按此序从左到右（确定性，重连/回放同序）。

#### 4.1.4 数字段（需求 3）

- 长条右端 0.72m 段，平贴 TMP（沿用 [`EnsureFlatCellLabel`](../Assets/Scripts/HotUpdate/UI/Framework/Battle3D/BattleFieldView.LandsHeroes.cs#L285-L307) 的平贴口径：`LookRotation(down, forward)`，`localScale = 1/TileScale` 补偿）。
- 文案：`{填充}/{上限}`，紧跟一行小字 `地牌`；如 `4/5`。
- 颜色：填充=上限时金色（满槽），未满白色；上限提升时数字上跳脉冲。

#### 4.1.5 退役项（同一对账里熄掉，防重影）

- 4 格的 `BattleTileFx.AddElement` 元素图标 → 改为长条上每段色带端一枚小图标；
- 4 格 `EnsureFlatCellLabel` 的 `可用/上限` 文字 → 移到长条数字段；
- `BattleTileFx.SetLandGlow` 逐格锁色环 → 改为长条对应色带高亮（保留 API，改由长条调用）。

#### 4.1.6 3D 射线横置

- 面片 collider 名 `land-quad-{rid}`（同时保留 `land-strip-{owner}` 与 4 格 `tile-*` 兜底）。
- [`PollFieldPointer`](../Assets/Scripts/HotUpdate/UI/Screens/BattleScreen.Board.cs#L69-L142) 在 `hitName` 分支前加：
  - 命中 `land-quad-*` → `OnLandQuadClick(rid)`；命中 `land-strip-*` → 按 x 反推格后开 Information。
- `OnLandQuadClick`：
  1. 从 `Core.ElementPool.GetPooledCards(P1)` 找 `RuntimeId` 对应的 `PooledCard`；
  2. 直接 `GameActions.TapLandForElement(Core, P1, pc.SourceCard, out reason)`（引擎自带时点闸、横置闸、冻结闸）；
  3. 成功 → toast `已横置 {卡名}：生成 1 个{色}临时元素`；`RefreshField()` 对账（面片横置态、5 分格 +1、数字段不变）；
  4. 失败 → toast 引擎真因。
- 教学/联机前置：教学走引擎 `TutorialPlayGate` 同口径（现 `GenerateFromLand` 已有 toast 闸，照搬）；联机当前不支持（toast 拒绝，阶段 3 再接 intent）。

### 4.2 左下 5 分格 + 费用粒子（需求 2）

### 4.3 手牌拖拽（需求 4 / 5）

#### 4.3.1 交互骨架

- `HandFanCard` 实现 `IBeginDragHandler / IDragHandler / IEndDragHandler`（当前只有 Pointer 三件套，[L25](../Assets/Scripts/HotUpdate/UI/Framework/HandFanCard.cs#L25)）；
  逻辑下沉到 `HandFanView`，屏侧只注入回调（沿用 `FanInteractions` 模式）。
- `HandFanView` 新增：`Dragging`、`DraggingCard`、`_dragOffset`；`RebuildTargets` 跳过拖拽卡；

- 起手（位移 > 12px 或长按 0.15s）：清悬停 → `Collapse()`（手牌缩到最小档，已有 `CollapseSinkRatio`）
  → 卡放大 1.15 + `SetAsLastSibling`。
- 跟手：屏幕点 → `RectTransformUtility.ScreenPointToLocalPointInRectangle(layer, …)` 写 `Pos`，
  `ApplyTransform` 直写（不走 tween）。
- 松手：见 4.3.2。

#### 4.3.2 落点判定表（IEndDrag）

| 落点 | 判定方式 | 结果 |
|---|---|---|
| 3D 地牌长条 / 面片 | `Physics.Raycast` 命中 `land-strip-*` / `land-quad-*`（或命中 `tile-*` 且 `CellRole.Land` 且 owner=0） | 卡可作地牌 → **放地**：锁色 = 指针所在色带（灰/红/蓝/绿）；卡有该色 → `LandFinal`；无该色 → `PickLandColorAsync` 兜底。不可作地牌 → toast 回手 |
| 3D 战场其它格 | `Physics.Raycast` 命中 `tile-*`（非地牌行）/ `hero-*` / `unit-*` | **发动**：复用 `OnFanUse` 全链（`GateMyMain` → `CanAffordCast` → `PlayCardFinal`）。**生物/结界落位 = 射线命中的空单位格优先，该格不可用则自动 first-free**；场地卡 = 场地格；法术 = 自动 first-free、**不取落点** |
| 屏幕边缘装饰带 | 未命中任何 `tile-*`（Env 装饰 `side-tree-*` / `crypt-*` / `pit` / `flat-ground` 等）或指针在屏边 80px 内 | **取消**：回手 + `RestoreFan` + 收箭头 |
| 手牌区自身 | UGUI 命中在 `self-fan-layer` 子树 | 取消并保持收扇（等同点扇外） |
| 其它（Region/Information/HUD 面板） | UGUI 命中 | 取消 |

> "指向战场就算发动"的语义边界：拖拽只表达**意图**；费用/目标/阶段/教学闸仍由既有链判定，
> 拒绝 = toast 真因 + 回手（绝不静默吞）。

### 4.4 输入路由与互斥（必须同批改）

1. **拖拽期让路**：[`PollFieldPointer`](../Assets/Scripts/HotUpdate/UI/Screens/BattleScreen.Board.cs#L69-L142) 开头加
   `if (_selfFan?.Dragging == true) { _hoverProv.Clear(); return; }`（放在开场闸之前、`OverUI` 判断之前）。
2. **抬起帧吞点击**：`IEndDrag` 结算后立即 `BattlePointer.ConsumeConfirm()`；否则同帧 `ConfirmPressed`

4. **收扇轮询**：`PollOutsideClick` 拖拽期跳过；回手后恢复正常。
5. **面片点按反馈**：`BattleTilePress.Play` 只对 `tile-*` 生效；面片点按在 `OnLandQuadClick` 内自带缩放反馈（不触发整格下沉）。
