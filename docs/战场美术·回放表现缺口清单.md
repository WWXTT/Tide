- **主配覆盖 25/28**（4 色 × 7 角色），缺 3：蓝 Buff、蓝 Shield、灰 Shield。
- **7 条次选在当前表序下永远不命中**：`Find` 取同色同角色首条（[BattleVfxCatalog.cs:44](../Assets/Scripts/HotUpdate/UI/Framework/Battle3D/BattleVfxCatalog.cs#L44)），次选只有调序才生效。
- **2 条 Shield 有配无调用点**：全仓 `BattleVfxFx.*` 只调 Cast / Projectile / Hit / Area / Heal + `TrySpawnPersistent(Buff)`（[BattleZoneProps.cs:117](../Assets/Scripts/HotUpdate/UI/Framework/Battle3D/BattleZoneProps.cs#L117)）。
- **结论（重建后 40 条）**：真正会演出的是 **33 条** = 20 条一次性路由（Cast4 + Proj4 + Hit4 + Area4 + Heal4）+ 3 条牌库常驻 Buff + 2 条 Shield（2026-11-13 起被"正面赋予"消费）+ 4 条 Summon + 4 条 Death；仅剩 **7 条次选**不产出画面（调序即换件）。
- **Summon 角色**：CastPlayed 的召唤演出仍归 `BattleCastArrival`（不入表）；本角色只管"其他来源入场"的轻量汇聚。
