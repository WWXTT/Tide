# 逐步驱动共享（BattleDecisionLoop）重构计划

> 状态：**S1 已签收 / S2 已签收 / S3 已完成（2026-11-27）**｜S2 口径见 §6｜派发对象：ZCode（阶段化，一次一阶段）

## 0. 背景与证据（先把问题钉死）

同一 checkpoint（红教师 `last`@150,528）、同一 ONNX（argmax）、同一 36 局协议（3 主题 × 先后手 × 6），只换驱动：

| 驱动方式 | 总胜率 | vs 红 | vs 绿 | vs 蓝 |
|---|---|---|---|---|
| 整回合驱动（`NeuralAI.TakeTurn`，游戏/编辑器 AI 对战路径） | **19.4%**（7/36） | 8% | 42% | 8% |
| 逐步驱动（`TideHeadlessDriver` + ONNX） | **63.9%**（23/36） | 83% | 58% | 50% |
| 训练口径（逐步、采样）评估 300 局 | 58.3% | 44% | 64% | 67% |

⇒ 模型本身没问题；**整回合驱动是错的**。逐步驱动与评估口径一致（63.9% vs 58.3%）。

代码事实（`Assets/Scripts/HotUpdate/AI/NeuralAI/NeuralAI.cs`，87 行）：
- `TakeTurn` 只枚举「回合玩家」的 main 阶段动作 → ONNX 选 → Apply → 直到 EndTurn；
- **无响应窗口停靠**（Guard / RespondPlay / PassPriority 从不让模型决策）；
- **无目标拾取（A6 / 宏行 picksRemaining）停靠**，靠 `TargetSelectionService` 自动选；
- **无循环收口 / 动作预算**（训练 driver 有 L1/L2/L3 剪枝与 `max_episode_steps`）；
- 观测只在「回合玩家 main」构建，与训练决策点分布不同。

## 1. 目标与非目标

**目标**：把训练侧 `TideHeadlessDriver` 里的「决策点循环」抽成公共组件 `BattleDecisionLoop`，**训练与游戏共用同一套**：
- 训练侧：`TideHeadlessDriver` 改为持有该 loop（对外 TCP 协议 reset/step 的请求与 info 键集合**不变**）；
- 游戏侧：`NeuralAI` 改为用同一 loop 驱动（每个决策点：Main / 响应窗 / 目标拾取），不再自己写回合循环。

**非目标**（本计划不做，除非另行签字）：
- 不改卡表、规则、观测布局（v22：191×158 / 100 / 512×26）、动作布局；
- 不改训练超参（chain 0.02 / λ0.98 / macro）、不改评估协议；
- 不引入搜索、不改 SimpleAI 行为（Script 大脑路径必须逐位不变）；
- 不做 HybridCLR/构建产物相关改动。

## 2. 设计要点（S0 需先核对，S1 再落地）

- 策略接口：`IBattlePolicy { int Select(float[] obs, LegalActions legal); void Reset(); }`；
  `OnnxTidePolicy` 实现它；训练侧由 Python 侧返回动作（driver 保留"每决策点发一次请求"的现状）。
- `BattleDecisionLoop` 职责（从 driver 搬出，去掉编辑器/协议专属）：
  1. `AdvanceToDecision()`：推进到下一个决策点（Main / Standby 响应窗 / 目标拾取步 / 终局）；
  2. `Enumerate()`：按停靠类型产 `Main` 行或 `Responses` 行（复用现有 `LegalActionEnumerator` / `EnumerateResponses`）；
  3. `Apply(index)`：应用成功/失败处理、`TrackModelBehavior` 行为计数、`TargetPickGate` 逐目标拾取；
  4. 循环收口：L1 指纹 / L2 预算 / L3 步数上限（driver 私有状态一并搬）；
  5. 终局收口：GameOver / 超时 / 上限，填 `Winner/Reason/Turn`。
- **边界**：`ResetCore` 里与"训练口径"强绑的部分（deck 建、handoff 开手脚本、modelSeat 钉死、`info` 组装、`_decider` 语义）保留在 driver；loop 只吃「已初始化好的 GameCore + 策略 + 配置」。
- 游戏侧接线：`BattleController` 的回合推进处，把 `NeuralAI.TakeTurn` 换成 `BattleDecisionLoop.RunUntilTurnEnd(policy)`；响应窗（`ResponseWindowService`）与目标拾取（`TargetSelectionService`）在神经座必须让位给 loop（Script 座不变）。
