# 一期训练 · 期望与验收契约（2026-11-24 定稿）

> **用途**：给「执行者」（ZCode / 任何模型）和「验收者」（DSH / 你）一份**同一口径**的期望与验收点。
> **与计划的关系**：《[回到一期训练目标](回到一期训练目标.md)》是**这一轮的施工计划**；本文是**跨轮不变的标准**。
> 计划里每改一次环境，都回本文对齐；本文与计划冲突时，以本文为准，并同批改计划。
> **状态**：全部条目「未实现」；任何一条只有在验收者拿到落盘产物、且你签字后，才可标「已验收」。

---

## 0. 三条总原则

1. **环境先于训练**：观测 / 动作 / 塑形 / 判据 / 续训，任一未定，不开训。
2. **口述不算验收**：每个验收点都必须有**落盘产物**（路径写死，见 §3）；没有产物 = 未做。
3. **只认一个版本号**：一次开训只有一个 `LAYOUT_VERSION`。本轮 **v21 = 158 / 100 / 20 / 191**。

## 1. 角色与节奏

| 角色 | 做什么 | 不做什么 |
|---|---|---|
| 执行者（ZCode 等） | 一次只做一个可独立验收的阶段；做完停；列出「改动文件 + 验证命令 + 产物路径」 | 不自行进入下一阶段；不放宽判据；不改用户定案 |
| 验收者（DSH） | 只看产物：读文件、跑命令、对原始行；抽查代码/注释/文档一致；grep 旧值 | 不采信汇报；不代签「已验收」 |
| 用户 | 拍板定案、签「已验收」、决定派活 | —— |

**状态机（只走这三态）**：`未实现 → 待验收（产物齐） → 已验收（用户签）`。
禁止：跳过「待验收」直接写「已验收」；用「已完成 / 已落地」代替产物。

## 2. 七条不变式（期望 ↔ 验收点）

> 每条：**期望**（可判定的一句话）｜**验收点**（命令 / 产物）｜**通过标准**。

### I. 口径显式
- **期望**：一期只认 `opponent=simpleai`；run 名、`config.json`、启动横幅三处都写口径，且代码断言，不靠人看。
- **验收**：`preflight_phase1.py` 断言命中；`config.json` 含 `opponent` / `criterion_era` / `layout_version` 三字段且与 run 目录一致。
- **通过**：非 `simpleai` 时 preflight **拒绝启动**、`certify_phase1.py` **拒绝出证**；三字段与 run 名一致。
- **反例（已发生）**：11-23 起 17 个 run 全带 `--model-theme all`，唯缺 `opponent`，人眼看不出漂移。

### II. 布局唯一
- **期望**：v21 定稿 `LAYOUT_VERSION=21`、卡特征 **158**、globals **100**、动作 **20** 维、卡槽 **191**；C# / Python / verifier 三方一致；训练副本与主仓字节相同。
- **验收**：`grep -rn "NGlobal = \|N_GLOBAL_FEATURES = \|LAYOUT_VERSION = "` 三方同值；`TideObservationDeckVerifier` ⓪ 通过；`grep -rn --include=*.cs --include=*.py "NGlobal = 97\|N_GLOBAL_FEATURES = 97\|158/97" Assets tide_rl` **代码里 0 行**（文档引用旧值不算）；主仓↔`Tide_train` 关键文件 SHA256 逐对相同。
- **通过**：三方同值 + 旧口径 0 行 + 哈希全同。
- **反例（已发生）**：自述“三特征已并进 v21”，磁盘 `NGlobal = 97`、全仓无 `g[97..99]`。

### III. 观测自证
- **期望**：牌库块 = 唯一卡分组 + 张数；己方标签与对方同函数同口径；截断不静默。
- **验收**：`Logs/DeckVerifier_<时间>.log`：绿 4 组 `19/19/11/11`、红 5 组、蓝 4 组；`g[88..95]` 逐维等于 `DeckTagsOf(OriginalDeckOf(me))`；对方 `g[50..57]` 与旧版逐维相等；其它区 `[157]=1`；布局握手 21/158/100/20/191。
- **通过**：只剩 ⑨ 牌库顶两条既有红（11-18 起断链，见 `AI训练说明.md §8`）；其余全绿。

### IV. 动作有界且终止
- **期望**：回合末弃牌**逐张**、每步 1 张、共弃 `max(0, 手牌数 − 上限)` 张；无合法行必兜底；动作行 ≤ 512 不截断。
- **验收**：`audit_action_space.py --episodes 100` 零截断；9 张手牌/上限 7 时出现 **2 个连续弃牌步**、每步每张手牌一行；`LaeMultiTargetVerifier` ⑧ 按新语义通过。
- **通过**：以上三项 + 脚本局 20 种子改前改后逐局一致（脚本座路径未动）。

### V. 塑形同源
- **期望**：手牌 **3/张固定**（不乘卡面费）、地 **2/块**、横置产色净 **+1**；代码、注释、文档同一口径。
- **验收**：编辑器探针 Φ 变化 = `+3 / +2 / +1`；手牌 7 张时手牌项 = 21（第 8 张仍 +3）；《[计价与塑形_统一口径](计价与塑形_统一口径.md)》§1/§2/§3 与代码逐条对上。
- **通过**：探针三项 + 文档三节无矛盾 + 全仓 grep 旧值结果列出。

### VI. 判据可证伪
- **期望**：`Δ = 模型 − 同格脚本基线`；区间判定；饱和格不退步；选点与判达标分离。
- **验收**：`test_phase1_criterion.py`（合成单测：真实 Δ=+10pp 的 1000 次抽样，通过率 **60–75%**）；`certify_phase1.py` 输出逐格 Δ / Wilson 区间 / 加测清单。
- **通过**：17 常规格每格点估计 Δ ≥ 0（区间跨 0 的先加测）、中位数 ≥ +15pp、饱和格 ≥ 基线 −5pp；每格 **200 局**（`σ_Δ ≈ 5pp`，95% 区间 ±10pp）；训练内每格 24 局的门只用于选点/预警。

### VII. 可续训
- **期望**：`--resume` 恢复权重 + 优化器状态 + 优化器步数 + 全局步数；崩溃/断连自动拉起；环境指纹不符即停。
- **验收**：序列化往返单测（恢复后走一步梯度，结果与不中断逐位相同）；副本小 run 中途杀掉 → 包装器拉起 → 步数连续、LR 按累计步数、KL 无尖峰、结束写 `COMPLETE`。
- **通过**：单测 + 杀进程实测两件都过；连续崩溃 3 次/10 分钟留 `STALLED` 并停。

## 3. 证据规则（产物路径表）

| 事 | 产物 | 位置 |
|---|---|---|
| 观测断言 | `TideObservationDeckVerifier` 输出 | `Logs/DeckVerifier_<时间>.log` |
| 动作审计 | `audit_action_space.py` 输出 | 同目录 `Logs/ActionAudit_<时间>.log` |
| 判据单测 | `test_phase1_criterion.py` | 退出码 + 控制台（贴进汇报） |
| 基线重测 | 逐格 json + `BASELINE_ERA` | `tide_rl/logs/` 与代码常量 |
| 评估矩阵 | `eval.jsonl` / `matrix_eval_*.json` | run 目录 |
| 训练状态 | `stats.jsonl` / `config.json` / `COMPLETE` | run 目录 |
| 开训认证 | preflight 指纹（版本/三维/卡表/ERA/判据） | run 目录 `preflight.json` |

**规矩**：每个数字必须能指到某行（文件 + 行号或字段）；推断明确标「推断」；引用历史读数标 `era`。

## 4. 变更规矩

- 改任一不变式 → **同批**改：代码 + XML/行内注释 + 本文 + 《回到一期训练目标》+ 相关文档（《AI训练说明》《计价与塑形》《观测方案》）。
- 形状变化（卡特征/globals/动作维）→ 必升 `LAYOUT_VERSION`，且旧 ONNX/fixture 全部作废。
- 旧值不删，标「已废弃（日期 + 原因 + 替代口径）」。
- 改动交付时列 `grep` 旧值结果；发现“代码与注释/文档矛盾”即判未完成。

## 6. 已知红灯（每次验收都先查这几条）

1. run 名/主题全对、`opponent` 掉了（11-23 漂移）。
2. 门槛写成“基线 +15pp 不封顶”，高基线格变成不可能（绿镜 97.8 → 112.8）。
3. 主仓改了、训练副本没同步（或反之）。
4. `FoldEquivalentRows` 把“来源区不同”的行折叠掉。
5. 训练进程非正常死亡、丢步，且没有续训守护。
6. 文档里的数值与代码现值不一致（例：《计价与塑形》§2 写 1.0×DerivedTier，代码是每张固定 1.0）。
