> **状态：已验收（2026-11-26 合并定稿）**。一期（帧模型/播放器/演出数据/本地回放/时间轴/日志行流）与二期（本地实时 LiveData / 联机数据面 / 联机录制回放 / 观战）均已落地——2026-11-12 commits `efd8935ef`、`2493ea122`；协议现役 **v20**（`MatchLogFull=137`）。

## 0. 结论

1. **演出 = 剧本回放**：三种来源（本地实时 / 联机实时 / 回放）产同一种 `BattleFrame`，共用唯一播放器 `BattlePlayhead`；回放额外支持 `SeekTo`。
2. **日志 = C 案行流**：服务端 `MatchLogLineStream` 单源渲染、`NetLogBatch`(135) 下发，客户端只 `AppendServerLine`；本文不改其语义。
3. **回放 = 录制剧本 + 时间轴**：终局自动录 film（座位遮蔽行 + 终局 `MatchLogFull=137` 全量行按 `EventId` 回填）；回放时战报面板=时间轴（全部行预铺、当前行高亮、点击跳转）。

## 1. 架构（现状）

```
引擎事件   ──▶ LocalFilmSource  ─┐
服务器下行 ──▶ NetFilmSource    ─┼──▶ BattlePlayhead（LiveData / Replay）──▶ IBattleStageSink
剧本文件   ──▶ ReplayFilmSource ─┘        每帧：PreOps → View → Ops → 行 → 等视觉 → 节拍
```

### 1.1 组件

| 层 | 组件 | 文件 |
|---|---|---|
| 帧模型 | `BattleFrame` / `BattleLogLine` / `BattleFilm` / `BattleFilmHeader` | `UI/Screens/Battle/Playback/BattleFilm.cs` |
| 播放器 | `BattlePlayhead`（LiveData/Replay、`SeekTo`、看门狗、`WaitingForInput`、时间轴游标） | `Playback/BattlePlayhead.cs` |
| 舞台协议 | `IBattleStageSink`（ApplyView / ExecuteFx / AdvanceTimeline / PlayCombat / WaitVisuals） | `BattlePlayhead.cs` 头注 |
| 演出数据 | `BattleFxOp` + 16 种 `BattleFxKind`；`FxRef` 为视图引用（不持引擎对象） | `BattleFilm.cs` |
| 执行器 | `BattleFxOpExecutor` → `BattleFieldView.PlaybackFx.cs`（ref 版 11 入口） | 同左 |
| 战斗演出 | `CombatShot` / `CombatShotPlayer`（`PlayCombatShotAsync`） | `BattleFilm.cs`、`PlaybackFx.cs` |
| 生产者 | `LocalFilmSource` / `NetFilmSource` / `ReplayFilmSource` | `Playback/*.cs` |
| 录制 | `BattleFilmStore`（`persistentDataPath/Films/<matchId>.film.gz`，保留 20 局，不进云） | `Playback/BattleFilmStore.cs` |
| 回放屏 | `BattleMode.Replay` + `BattleScreen.Replay.cs` + 时间轴 | `BattleScreen.Replay.cs`、`BattleEntry` |
| 日志行流 | `MatchLogLineStream` + `NetLogBatch`(135) + `MatchLogFull`(137) | `CardCore` 侧 |

### 1.2 三种帧来源

- **LocalFilmSource**：`StackResolutionStart/End`、`StackEmpty` 建帧；`View=CaptureSnapshot()`；行来自本地 `MatchLogLineStream`（`redact=false`）；投影器钩子捕获 `BattleFxOp`（只录不执行）；编舞器把攻击步写成 `CombatShot`；终局 `BattleFilmStore.Save`。
- **NetFilmSource**：事件源 = `EventFeed.FxOnly` 的 `NetEventBatch`；行 = `NetLogBatch` 的 `NetLogLine`（按 `EventId` 归帧）；`Ops = NetFxMapper`；`View` 在快照到达时投（决策点粒度）。**交互数据与播放解耦**：候选/计时/快照立即更新，只有渲染+行+演出按节拍走。
- **ReplayFilmSource**：`Load(id)` 逐帧投 `Replay`；不询问输入；`Input` 帧只展示。

### 1.3 播放器两种模式

- **LiveData**：边产边投；帧内五段全经 `IBattleStageSink`；节拍本地 900ms / 联机 350ms，积压 >6 帧压缩停顿；队列放干且回合未完 = `WaitingForInput`。
- **Replay**：整包投帧、同一帧体；末帧 `End` 收卷；不询问、不等待；`SeekTo(frameIndex)` 跳段首继续播。

## 2. 已定口径（不再讨论）

| 事项 | 决定 | 说明 |
|---|---|---|
| 联机演出数据 | **E1 `EventFeed` 三态** `None/FxOnly/Full` | 人类座位与观战 = `FxOnly`（演出白名单事件 + 三个结算边界）；AI 填位 = `Full`。异常时 `Full` 一行回退 |
| 回放无遮蔽 | **E2 `MatchLogFull=137`**（复用 `MsgNetLogBatch` 载荷） | 终局在最后一拍事件/行之后按座位发全量无遮蔽行；客户端按 `EventId` 回填 `FullText` 并重写 film |
| 本地遮蔽 | **E3 本地不遮蔽**（`redactHidden:false`） | 本地只有一名人类，AI 信息无保密需求；与 C 案「本地逐字不变」一致 |
| 演出指令 | 数据（`BattleFxOp`），不是闭包 | 闭包不可录制、不可跨端 |
| 输入等待 | 生产者侧（帧未产生） | 回放天然无等待；`IBattleInputGate` 只预留 |
| 录制与 matchId | 客户端开局生成一次（`EncounterStore.NewMatchId()`） | film 文件名与 `EncounterRecord.matchId` 共用；断线未收到全量行 → 退回遮蔽版 |
| 观战 | 与玩家端同构（FxOnly + 全量行 + fullInfo 快照），**不录制** | 中途加入从加入点起 |
| 回放入口 | 大厅 `btn-replay`（预制体已有） | 有 film 才可点；`BattleEntry.Mode=Replay` 复用同一战斗屏 |

## 4. 已知限制

1. **E1 白名单漏类型 → 联机缺演出**：补一行事件类型即可，不动协议；异常时 `EventFeed=Full` 回退（带宽回现状）。
2. **联机局面粒度**：快照只在稳定决策点，事件帧没有逐帧局面。
3. **回放战斗精度**：只还原「飞行/命中/伤害/死亡」；守卫闪现/反击/溅射走位不还原（战报行照常）。
4. **输入闸**：回放不询问、不等待；`IBattleInputGate` 仅预留。
5. **回放行数**：>1000 行按步降采样，跳转粒度=步。
6. **云存档**：film 不进云；历史行无 film 时 `btn-replay` 保持灰。
7. **体积**：单帧 `BattleViewData` JSON ≈5–20KB；整局 100–500KB（GZip 后更小）。
8. **全量行缺省**：断线导致 `MatchLogFull` 未达 → 复盘退回遮蔽版。
9. **观战不录制**；中途加入只从加入点起播。

## 5. 明确不动

- 线格式：快照 / `NetEventProjector` / intent / 反问通道；
- C 案行流语义：`MatchLogLine` 载体、`NetLogBatch`(135) 时序与文字；
- 隐藏信息过滤（`NetEventSeatFilter`）与观战全信息口径；
- 服务器对局驱动（`PumpEngine` / 计时 / 座位）；
- 预制体版式与「UI 只绑定不生成」铁律；
- 教学导演 / AI 驱动 / 响应窗 / 目标选择语义（只换表现层挂点）。
