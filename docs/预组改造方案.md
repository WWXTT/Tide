# 三预组改造方案（2026-11-02）

> 目标：三套卡组"打得有来有回"（45-55%），各自发挥格子特色，并且都能应对"预料之外"的对手。
> 三套同时作为**结业考试**：连续打赢三关才解锁排位。
>
> **2026-11-04 命名调整**：三色显示名改为 **红→火 / 蓝→水 / 绿→植物**；预组卡改名：
> `火种·锐→火苗`、`火种·厚→余烬`、`赋予连击→追击`、`棘爆→爆荚`、`寒锥→潮汐`、
> `潜影碑→潮痕碑`、`深潜碑→深潭碑`、`重放→余波`。旧文里的旧名按此对应。

## 0. 三条硬约束（从现有引擎事实出发）

1. **地牌行每方 4 格、每色 1 格** → 单局能产出的颜色是有限的，跨色卡基本等于废卡。
   当前蓝套的 `回潮(红1)×4`、`洗回(绿3)` 就是这个问题的受害者。
2. **单位区每方 9 格（近中线 5 + 后方 4）** → 铺场型卡组的上限是 9，超过就是空手牌。
3. **格子特色 = 位置 + 节奏**：近中线 5 格先接触对手，后方 4 格是"养"的位置。

> **代价=摧毁己方地（2026-11-04 改版）**：火种统一 2/2 后，原「对己方单位造成 2 点伤害」会直接打死目标，

> 第 4 块地只会把奖励门关死（`RedAggroStrategy.ShouldLand` 钳在 3；3 块之前仍只铺「打不出的牌」，
> 不主动烧能打的牌）。
> **活体炸弹（2026-11-04 新 Key 牌，×2）**：3 红、**无代价**（BurstDamage 锚红 3；有限分支奖励免费）。
> 效果 = 弹选己方最高攻生物当参照 → 对一个对方单位造成等同其攻击力的伤害（结算期选，默认打脸）；
> **本回合第一张卡**时奖励 2 伤（`FirstCardThisTurn`）：对手生命 ≤2 时补刀直接赢，否则优先解能一击打死的
> 小阻拦生物（带守护/正在拦截者优先），都不成立才补脸。和血偿的分工：**血偿是「伤害砸守卫开路」，
> 活体炸弹是「主伤砸脸 + 奖励杀小守卫」**——守卫生命 ≤2 时活体炸弹更赚（多一份打脸伤害），
> 守卫大时才用血偿硬开。红只 3 地，付得起就抢本回合首卡；已经出过别的牌就留手到下一回合，不白丢奖励。
> 为腾卡位：血偿 5→4、连击 5→4。
> **关键词两通道（2026-11-03 终版·单行制）**：原子表**只留印刷行**（连击 `8c988c18`、再生 `ea1df378`，
> 域={自己}）；「赋予」= 同一条印刷行 + **实例域 kinds=[1]**——装载校验 `IsKeywordStyleEntry` 按
> **实例域**判（纯自指才剔除），所以印刷行挂 `[1]` 就是赋予、可作主动。合成器加关键词走赋予
> （`EntryForEffectSlot` 自带 kinds=[1,2]），卡面印刷走 `CardData.Keywords`。
> 原 `327e9a87 赋予连击` / `f1f22aa6 赋予再生` 两行已删。
> 菌丝：印刷再生行锚价是**绿6**，要「减甲 + 留 1 绿」只能把该效果**锚价钉死为绿3**（`costPin`，
> 手作教学行口径；不改原子表，避免联动「守誓」那张印刷再生的价）→ 代价对手+4护甲 → 净 **绿1**。
> **角色技能限制（2026-11-02）**：`HeroSkillSystem` 新增 `SkillBranchViolations`——技能卡不得挂
> 槽级分支载荷（手牌为0抽1 / 产出条件 / 引擎奖励），与既有「不得带代价 / value≤1 / 速度恒 0」同闸。
>
> AI（RedAggroStrategy v7）六条：① 对手有可阻拦生物 → 加攻/连击/激励优先给**高生命**单位；
> ② 斩杀线按**连击双倍伤害 + 活体炸弹打脸值**算（法术结算即中，比生物攻击更可靠）；③ 火灵·守没有大哥前留手，先下火灵·攻；
> ④ 大哥=被火灵 +2 攻养到 **4 攻**的 2/2 火种（攻击最高者），只具备 +攻时**分散**加攻；手里连击可放且对手无阻拦时
> 改**集中**爆发；⑤ **放地停在 3 块**（保 `LandsLe3` 抽牌门）；⑥ **活体炸弹抢本回合首卡**：参照取最高攻，
> 主伤打脸，奖励先补刀/解小阻拦；出过牌就留手。补充（同日）：攻击被守卫拦下时走响应窗
> 二选一——**连击先制无伤清障** vs **直伤开路让攻击回到原目标**，按斩杀线与场面得失择一；
> 活体炸弹在响应窗能吃到首卡门且守卫生命 ≤2 时优先（打脸 + 奖励杀守卫，比血偿多赚一份打脸伤害）。

## 2. 绿·慢速 —— 特色：后方 4 格养大哥

**现状（30）**：新生×6 / 林地守卫×4 / 藤盾×4 / 晨露×3 / 回收×3 / 菌丝×2 / 棘爆×2 / 雾障×2 / 噬血藤×2 / 獠牙×2

> **2026-11-03 卡组已改（本节旧表作废）+ AI 跟进**——现卡组（费用均为**推导值**，costList 只是显示缓存；
> 共 **42 张**，30-60 张规则允许）：
> 培育×**8**（绿1：永久+1生命，**地≥9** 再+1攻击）/ 成长×**6**（主卡组，**绿3**：地牌上限**+2 并拉 2 张地**
> （横置入场）＝ 锚 6 − 代价「对手+6护甲」3）/
> 林地守卫×**5**（**1/9 · 绿5**，守护印刷）/
> 獠牙×**4** / 雾障×**3** / 棘爆×**3** / 噬血藤×**3** / 晨露×**3**（全部 **0/6 · 绿2**）/
> 菌丝×**5**（**绿3**：再生，代价对手+6护甲）/ 回收×**2**（**绿3**：墓地 2 张回手，同代价）；
> **英雄技能=流失**（**绿2**：一个目标流失 1 生命；LifeLoss 原子是红2 锚 → 锚价钉死绿2，0 速、不带代价）。
> 注：成长的代价是 6 层护甲 = 3 绿，**地牌门槛要求 3 块绿地**才能施放（1~2 地时打不出）。
> 倒计时优先级（2026-11-03 用户定案）：**帷幕（雾障）第一 → 狩猎（獠牙）第二**，
> 其余倒计时（棘爆/噬血藤）随后（出牌分 5000 / 4000 / 900）。
>
> AI 三条（用户 2026-11-03 定案，已实装于 `GreenRampStrategy`）：
> ① **培育不再自己回合打光**——留 1 张给「攻守宣言之后」的窗口：只在 +1 生命能把「被打死」翻成
>    「活下来」（来袭伤害恰等于参战单位生命）时才贴，属性在战斗过程中变化换优势；其余按成长打。
> ② **菌丝（再生）等对手回合**——自己回合留手，对手回合给**已受伤**的己方单位贴；
>    培育的落点优先给**已有再生**的生物（再生按最大生命回满，养它最赚）。
> ③ **倒计时优先狩猎**（没有狩猎这套牌没有进攻性）：獠牙出牌分置顶；狩猎/帷幕/溅射/警戒的奖励
>    落点改按**攻击力最高**（被培育养大的那只）；守护绑定「生命安全第一」——生命 &gt;10 时首个守护贴给
>    狩猎载体（獠牙/已带狩猎者），生命 ≤10 时改贴角色。
>
> 另修：旧 `ShouldLand` 会把整手绿费牌铺成地（新卡组全是 0/6 墙 → 场上一个单位都没有），
> 改为**每张留 1 张、只铺重复副本**，极早期（绿&lt;2 且地&lt;3）才牺牲单张。
> **狩猎结算口径（2026-11-03 引擎改）**：`CombatSystem.ResolveHuntAttacks` 不再走 `CanDeclareAttack`——
> 只要求「存活 + 未横置 + 攻击力 &gt; 0」，**NoAttack 不拦**（0/6 墙被培育喂出攻击力后也能在回合末白嫖一次攻击），
> 0 攻不打（否则纯自杀：0 攻打 3 攻会被反击打死）。

## 3. 蓝·控制 —— 特色：4 格地牌 + 结界延迟

> **2026-11-04 AI v4**：蓝 AI 以**带充盈的结界**（潜影碑/深潜碑）为引擎，潜影碑伤害为主制胜轴；
> 潜行（英雄技能「隐匿」）只给带充盈的结界，不再给角色；已删除旧「磨牌/疲劳斩杀 + 幻壁重放」口径，
> 回潮只作防自抽干，不再围绕双方过牌/回收运转。

**现状（30）**：乱锋×5 / 寒锥×5 / 回潮×4 / 深潜碑×4 / 潜影碑×4 / 逐出×3 / 薄壁×3 / 重放×2

| 项 | 内容 |
|---|---|
| 致胜轴 | `寒锥(0费冻结)` + `逐出(灰6 抹除)` 拖住对手，靠充盈引擎滚雪球 |
| 破绽 | **自己先抽干**（长局 40-50 回合）、无回收 |
| 反意外科技 | **洗回**（用户指定） |

**改法 —— 但有两个费用现实必须先解决**

| 卡 | 现价 | 问题 |
|---|---|---|
| `回潮`（弹回）×4 | **红 1** | 弹回原子已归红 → 蓝套付不起，**4 张等于废卡** |
| `洗回` ×2 | **绿 3** | 洗回原子是绿 1 → 蓝套同样付不起 |

**两个选项（需要你定）**：

- **A（改锚）**：把 `洗回` 原子改回蓝锚（或加"蓝锚特例"），再把 `回潮` 换成蓝锚等价物 → 蓝套能正常带洗回
- **B（换卡）**：不动原子，蓝套用"充盈引擎 + 洗回"的灰/蓝组合卡替代；`回潮` 直接删掉换成 `寒锥`/`乱锋`

我倾向 **A**：洗回是蓝套"不自抽干"的唯一手段，没有它长局必输。

## 4. 三套的克制关系（改造后预期）

```
红（直伤过墙）→ 克 绿（大哥被绕）
绿（帷幕防点解）→ 克 蓝（控制解不掉墙后大哥）
蓝（洗回续航）→ 克 红（拖到红手牌打空）
```

目标：每组 **45-55%**，平均 **15-25 回合**（现在的 31.5 回合偏长，说明三套都太慢）。

## 5. 结业考试（三关 Gate）

**规则**
- 三关固定顺序：红 → 绿 → 蓝（或玩家自选顺序）
- 玩家可用**自组卡组**或**预组**挑战
- **允许保持胜场**：打赢第 1 关后输了第 2 关，重试从第 2 关开始，不用重打第 1 关
- 三关全过 → 解锁排位赛资格 + 获得"对原子表费用提意见"的权限

**实现要点**

| 项 | 方案 |
|---|---|
| 进度存储 | `ExamProgress { int passedLevel; int totalAttempts; }`，本地存档 |
| 关卡数据 | 复用三预组 + 对应 skill 卡 + 策略脚本（与 AI 训练同一份） |
| 失败处理 | 弹窗"重试本关 / 返回主界面"，`passedLevel` 不回退 |
| 通关奖励 | 置位 `RankedUnlocked` + `CostFeedbackUnlocked` |
| 反作弊 | 考试局禁用自定义卡组以外的改表？——**不禁止**，但你明确说过允许自组，所以只记录卡组来源 |

## 6. 落地顺序

1. **先定蓝套的两个费用问题**（A 改锚 / B 换卡）——这是唯一阻塞项
2. 按上表改三套卡表，跑 `Tools/重推导测试卡表费用与ID`
3. 三组各 100 局验证：胜率与平均回合是否落到目标区间
4. 再做考试 Gate（属于表现/流程层，可后置）
