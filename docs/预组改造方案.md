# 三预组改造方案（2026-11-02）

> 目标：三套卡组"打得有来有回"（45-55%），各自发挥格子特色，并且都能应对"预料之外"的对手。
> 三套同时作为**结业考试**：连续打赢三关才解锁排位。
>
> **2026-11-04 命名调整**：三色显示名改为 **红→火 / 蓝→水 / 绿→植物**；预组卡改名：
> `火种·锐→火苗`、`火种·厚→余烬`（2026-11-13 并入火苗）、`赋予连击→追击`、`棘爆→爆荚`、`寒锥→潮汐`、
> `潜影碑→潮痕碑`、`深潜碑→深潭碑`、`重放→余波`。旧文里的旧名按此对应。
>

## 0. 三条硬约束（从现有引擎事实出发）

1. **地牌行每方 4 格、每色 1 格** → 单局能产出的颜色是有限的，跨色卡基本等于废卡。
   当前蓝套的 `回潮(红1)×4`、`洗回(绿3)` 就是这个问题的受害者。
2. **单位区每方 9 格（近中线 5 + 后方 4）** → 铺场型卡组的上限是 9，超过就是空手牌。
3. **格子特色 = 位置 + 节奏**：近中线 5 格先接触对手，后方 4 格是"养"的位置。

> **代价的四条口径（2026-11-13 定案，引擎已按此实现）**：
> ① **发动前闸**：声明期确认每张卡都有有效代价才允许发动——两张卡各自都还看得到那只唯一生物，
>    所以**两张都能上栈连锁**（同速 2 可接链）。
> ② **结算期先付代价，代价失败=该张效果无效**：`CostCompensationService.PayPayloadsAsync` 任一代价原子
>    无有效目标即返回 false，`EffectExecutionEngine` 空转该效果（只入墓、不结算）。
> ③ **参照在发动时取**：参照族（活体炸弹/活体护甲）的攻/命在**代价执行前**快照
>    （`EffectExecutionContext.RefPowerSnapshot`）——之后参照被自己的代价消灭/移走，本次伤害照落
>    （不再走「参照亡=空转」）。
> ④ **代价与门奖励不能并存**（自由分支/有限分支/代价三选一）：`DeckCompositionValidator.CheckEffectLegality`
>    在卡组校验面硬拦；活体炸弹原有的「本回合首卡 +2」门奖励**已删**（效果名/内容指纹同步更新）。
>
> **实测（`TideSim --chain-cast`，己方只有 1 只生物）**：
> · 先血偿 → 再活体炸弹（炸弹先结算）：炸弹按快照打 2、代价杀唯一生物；血偿代价失败 → **效果无效 0 伤**。
>   总伤 2、代价只付 1 次。
> · 先活体炸弹 → 再血偿（血偿先结算）：血偿 5（代价杀唯一生物）；炸弹代价失败 → **效果无效 0 伤**。
>   总伤 5、代价只付 1 次。
> 所以「3 费血偿 + 活体炸弹」不是 1 只生物能打出的 7 伤：**每张法术各吃一只己方生物**——
> 1 只生物时两张只能成一张（取更高的血偿 5）；**2 只以上才能 `血偿 5 + 参照攻`**（2/2 参照 = 7 伤）。
>
> AI（`RedAggroStrategy` 2026-11-13 收缩）：连击分支整删（进攻不再有「集中爆发」口径，
> 加攻只走「有阻拦给高生命 / 无阻拦分散」）；活体炸弹只当**终结牌**（`ShouldHold`：不能直接终结、
> 也不能和血偿凑斩杀就留手——不白送生物）；斩杀线 = 血偿 5 + 炸弹（参照攻，1 只生物时取较高那张）；
> `CardPlayScore` 让炸弹在凑斩杀时排在血偿**前面**；守卫响应窗只留血偿开路（炸弹不进响应窗）。
> 回归入口：`TideSim --tutorial-scenario`（固定盘面 ③④⑨：炸弹留手/不白送/斩杀排序）+
> `TideSim --chain-cast`（连锁两序、代价口径、参照快照）+ `TideSim --scenario`（策略闸）+
> `TideSim --deck-rule`（卡组校验：代价×门奖励互斥，含改版前炸弹形状的负例）。

## 5. 结业考试（三关 Gate）

**规则**
- 三关固定顺序：红 → 绿 → 蓝（或玩家自选顺序）
- 玩家可用**自组卡组**或**预组**挑战
- **允许保持胜场**：打赢第 1 关后输了第 2 关，重试从第 2 关开始，不用重打第 1 关
- 三关全过 → 解锁排位赛资格 + 获得"对原子表费用提意见"的权限

**实现要点**

| 项 | 方案 |
|---|---|
| 进度存储 | `ExamProgress { int passedLevel; int totalAttempts; }`，本地存档 |
| 关卡数据 | 复用三预组 + 对应 skill 卡 + 策略脚本（与 AI 训练同一份） |
| 失败处理 | 弹窗"重试本关 / 返回主界面"，`passedLevel` 不回退 |
| 通关奖励 | 置位 `RankedUnlocked` + `CostFeedbackUnlocked` |
| 反作弊 | 考试局禁用自定义卡组以外的改表？——**不禁止**，但你明确说过允许自组，所以只记录卡组来源 |
