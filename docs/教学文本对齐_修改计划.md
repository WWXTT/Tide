## 3. 已确认的问题（附证据）

**A. 讲解文本挂在操作闸上（#8–#11）**
`type` 仍是 element/activate/play（[TutorialConfig.json:117](../Assets/Configs/TutorialConfig.json#L117)），
闸按 type 卡死操作（[TutorialGuide.cs:320](../Assets/Scripts/HotUpdate/AI/TutorialGuide.cs#L320)、[:363](../Assets/Scripts/HotUpdate/AI/TutorialGuide.cs#L363)、[:378](../Assets/Scripts/HotUpdate/AI/TutorialGuide.cs#L378)），
但文本只讲规则、不叫玩家动手 → 玩家不知道「现在该干什么」，且误点结束回合时弹的是整段讲解。

**B. 动作说明挂在攻击步上（#12）**
「把教学·1 放进元素池当土地；再召唤教学·3」写在 `type=attack` 的步里——系统此刻等的是**宣言攻击**，
文本教的是**放地 + 召唤**。

**C. 新增的第二攻击步是硬卡死（#13）**
- 闸按 attacker **精确 id** 比对（[TutorialGuide.cs:285](../Assets/Scripts/HotUpdate/AI/TutorialGuide.cs#L285)）；
- 同 id 多张在场景注入时唯一化为 `id` / `id#2`（[TutorialScenario.cs:203](../Assets/Scripts/HotUpdate/AI/TutorialScenario.cs#L203)），
  所以 #13 要求的是**同一只**生物；
- 攻击宣言即推进（[TutorialGuide.cs:393](../Assets/Scripts/HotUpdate/AI/TutorialGuide.cs#L393)），第一击后该实例已横置 →
  第二击宣言不出来；
- 而 `GateEndTurn` 在 attack 步把结束回合钉住（[:304](../Assets/Scripts/HotUpdate/AI/TutorialGuide.cs#L304)）→ 既不能攻击也不能过回合 = 卡死。

## 4. 对齐规则（本轮落文案的唯一口径）

1. **一步一音**：`audio` 与 step 1:1，禁止一条音挂两步（现状仅 `basics_13` 违反）。
2. **type 由音频内容定**：讲规则 → `intro`（确定推进）；叫玩家做某个动作 → 用对应闸的 type（element/play/activate/attack/guard/end）。
3. **操作步 hint = 祈使句**：只写「做什么、在哪做」，不写规则讲解（操作步的 hint 会在拒绝提示里被玩家读到）。
4. **同 id 多张时禁止精确裸 id**：需要指名时写 `#N`，并在 `scenario` 里把注入顺序钉死；或改宽松闸。
5. **文案里的名字只用现役**：卡名取 `TutorialCards.cardName`；入口取第 1 节交互表（点击+按钮 / 头顶三键 / 【回合结束】）。
6. **效果描述必须在卡表里真实存在**：文本写「登场效果/衍生物」，卡表就得有对应 `effectIds`；否则先改卡表（并重推费用）或改文案。
