## 0. 目标与边界

**目标（第一轮）**

1. 4 个关键音效：抽牌 / 命中 / 死亡 / 胜负，事件驱动、可静音。
2. 2 套 BGM：主菜单 / 战斗；战斗 = intro → loop，终局淡出；教学沿用战斗曲并压音量。
3. 音量设置：**音乐/音效分轨**滑条 + 静音 + `PlayerPrefs` 持久化，重启保持。
4. 素材走「长曲切片 + 分段循环」路线，可扩展到「渐进」（分层 stems），但 v1 不要求。

**不做（本轮硬边界）**

- 不接 FMOD / Wwise / 第三方音频中间件；不新增包依赖。
- 不在战斗主链里同步 `Load`/同步播音频；不放 `Update` 轮询。
- 不用代码临时拼 UI（含滑条、静音钮）——一律预制体烘焙 + 按名绑定（AGENTS「UI 只绑定不生成」）。
- 不动训练环境：卡表 / 原子表 / 费用推导 / 观测布局 / 动作空间 / 三套预组。
- 不入库来路不明或「免费层禁止商用」的音乐。

## 2. 口径决策（派活前先定，之后改口径 = 返工）

1. **素材许可硬门槛**：只入库「明确允许商用」的素材。每个文件登记来源 URL / 作者 / 许可 / 生成或下载日期 / sha256；
   免费 AI 平台（Suno、Udio 等）若免费层条款禁止商用，**不得使用**——以生成当日条款截图为准，存 `.ztmp/audio/license/`。
2. **切片规格**：44.1kHz；BGM 用 ogg vorbis（q5，streaming 导入）；SFX 用 wav 16bit；
   BGM 响度 `-16 LUFS / TP -1.5 / LRA 11`，SFX 峰值约 `-3 dBFS`；循环点取小节边界，接缝试听 3 次无咔哒。
3. **系统形态**：`AudioMixer`（Master / Music / SFX / Voice）+ `AudioService` 单例；音量走 exposed 参数，
   线性 0..1 → dB（`20*log10(max(v,1e-4))`）。设置面板给 **音乐/音效两条滑条 + 静音**；
   教学配音（Voice）随 Master、不单列滑条（v2 再议）。
4. **事件驱动**：SFX 只在引擎事件回调里播；8 路 Source 池；同帧同类只播一次（防叠爆）；战斗主链零同步加载。
5. **UI**：音乐/音效滑条、静音、关闭按钮**烘焙进 MainUI.prefab**（命名固定，见 §4.5），代码只绑定；
   位置/样式由用户在编辑器里调预制体，代码不动。
6. **暂停**：沿用现有 `AudioListener.pause`；BGM/SFX 随暂停停，恢复继续（不从头）；教学配音保持 `ignoreListenerPause`。
7. **热更**：新增音频走 YooAsset。**2026-11-22 用户定案：新建 `Audio` 组收集 `Assets/Audio`**
   （Music/SFX 分包，BGM 可 lazy load）；`Assets/Art/Audio` + `ArtRuntime` 方案作废备选，不再采用。

### 3.1 来源地图与找法（A1，只读调研）——已完成（2026-11-22，两轮，结论见 `.ztmp/audio/A1_来源调研.md`）

**这一步只回答「从哪找、许可怎么看、凯尔特风怎么筛」，不下载、不入库。**

| 路径 | 候选 | 许可要点 | 备注 |
|---|---|---|---|
| 免版税曲库 | Pixabay Music / Free Music Archive / Incompetech / Jamendo | 逐曲 License；Pixabay License 可商用；FMA 多为 CC（BY / BY-NC） | 最稳；凯尔特曲目量大 |
| 免费 AI 音乐平台 | Suno / Udio / Mubert / Soundraw / Beatoven 等 | **免费层常禁商用**；以生成/下载当日条款为准 | 只在明确可商用档位使用 |
| 开源 AI 编曲模型（本地生成） | MusicGen / Stable Audio Open / ACE-Step / YuE / Riffusion / AudioLDM2 | **代码开源 ≠ 权重可商用**（多数学术权重 CC-BY-NC）；生成物许可随权重 | 逐模型核权重许可，可商用者才进候选 |
| CC0 / 公共领域 | Musopen / ccMixter / Wikimedia | 逐曲 CC0 / PD | 古典/器乐多，凯尔特需筛 |

**找法（A1 要交的东西）**

1. 每个来源给 1 条**可复现检索式**（例：`site:pixabay.com/music celtic instrumental`、
   FMA tag `celtic` + License 过滤、GitHub 搜 `celtic music` + `CC0`）。
2. **许可速查表**：能否商用 / 是否要署名 / 是否允许改编与切片 / 是否允许游戏内使用，四项逐来源填。
3. 凯尔特风筛选词：`celtic / irish folk / tin whistle / fiddle / harp / bodhrán / jig / reel / drone`；
   排除人声、排除 <60s 或 >6min、排除明显多段不循环的曲子。
4. 结论：给 **2 条推荐路径**（首选/备选）+ 各自风险；若开源模型权重全都不可商用，就明说
   「AI 生成路径不可用，只能走免版税曲库或自购授权」。

**A1 产出**：`.ztmp/audio/A1_来源调研.md`（一页：来源表 / 检索式 / 许可速查 / 推荐路径），不下载音频。
**A1 验收**：别人能按报告独立复现检索；许可速查覆盖四项；推荐路径 ≤2 条且写明风险。

### 3.2 切片流水线（A3）

选定 1 首后切四段：

| 段 | 用途 | 参考长度 | 处理 |
|---|---|---|---|
| `music_menu_loop` | 主菜单/大厅/构筑 | 30–60s | 小节对齐，`loop=true` |
| `music_battle_intro` | 进战斗一次性 | 8–16 小节 | 不循环，接 loop |
| `music_battle_loop` | 战斗主循环 | 60–90s | 小节对齐，`loop=true` |
| `music_battle_outro` | 终局/退场 | 8–16 小节 | 淡出用 |

命令模板（先粗切试听，再精切重编码）：

```powershell
# 粗切（不重编码，快）
ffmpeg -ss 00:00:12.0 -to 00:01:02.0 -i long.wav -c copy .ztmp/audio/rough_menu.wav
# 精切 + 响度归一 + ogg
ffmpeg -ss 00:00:12.0 -to 00:01:02.0 -i long.wav -af "loudnorm=I=-16:TP=-1.5:LRA=11" -c:a libvorbis -q:a 5 music_menu_loop.ogg
```

**循环验收**：导入 Unity 后 `loop=true` 连播 3 次，接缝无咔哒/无断拍；有咔哒→重叠 20–50ms 交叉淡化重切。
**A3 产出**：`Assets/Audio/Music/` 四段 ogg + 试听报告（loop 点、峰值、3 次循环结论）。

## 4. B 线：系统

### 4.1 总线与音量（B1）

- `TideAudioMixer.mixer`：`Master` → `Music` / `SFX` / `Voice`；exposed：`MasterVol` / `MusicVol` / `SfxVol` / `VoiceVol`。
- `AudioService`：启动初始化（`LaunchScreen` 或 Boot），`DontDestroyOnLoad`；停用/切场景不销毁。
- 默认音量：Music 0.6 / SFX 0.8；Voice 随 Master（1.0）。`PlayerPrefs` 键 `audio.music` / `audio.sfx` / `audio.mute`。
- 写入防抖 0.2s + `PlayerPrefs.Save()`；启动读取并 `SetFloat` 到 mixer。

### 4.2 AudioService API

```csharp
void PlaySfx(AudioClip clip, float volumeScale = 1f);      // 池化，8 路轮转
void PlaySfxAt(AudioClip clip, Vector3 pos);               // 3D（可选，v1 少用）
void PlayMusic(BgmId id, float fadeSec = 1f);              // 双源 crossfade
void StopMusic(float fadeSec = 1f);
void SetBusVolume(Bus bus, float v01);                     // 线性→dB
void SetMute(bool mute);
```

- BGM 双 `AudioSource`（A/B）交叉淡入淡出，用 **unscaled** 时间（暂停 `timeScale=0` 时也能收尾）。
- 加载：`HotUpdateAssets.Load<AudioClip>(name, path)`（与教学配音同口）；启动异步预载 4 个 SFX；BGM 按场景懒加载；
  失败 `Debug.Log` 静默，不阻塞流程。
- 内存：BGM streaming；SFX `DecompressOnLoad` + 常驻；不保留未使用 clip 引用。

### 4.3 事件接线（B2）

统一放一个 `BattleAudioBridge`（挂 `BattleScreen`），订阅 4 组：

| 事件 | 音效 | 备注 |
|---|---|---|
| `CardDrawEvent` | `sfx_draw` | 同帧多抽只播一次 |
| `CombatDamageEvent` + `AtomicDamageEvent` | `sfx_hit_light` / `sfx_hit_heavy` | 按伤害量分档；与 VFX 同拍 |
| `CardDestroyEvent`（生物/永久物）+ `RoleDeathEvent`（角色） | `sfx_death_unit` / `sfx_death_hero` | 角色死亡更重；同帧多死只播最强一档 |
| `GameOverEvent` | `sfx_win` / `sfx_lose` | 按本地座次判胜负；终局淡出 BGM |

- 回放/观战：同一事件流；**快进时按 `Time.unscaledDeltaTime` 节流**（每 0.1s 最多 1 声），避免机关枪。
- 不订阅 `LifeChangeEvent` 等高频事件（防刷）。

### 4.4 BGM 场景表与渐进（B3）

| 场景 | 曲目 | 行为 |
|---|---|---|
| MainMenu / Lobby / DeckBuilder / Composer | `music_menu_loop` | 同曲延续，不重启；进屏淡入 1s |
| Battle（普通/联机/教学/挑战） | `music_battle_intro` → `music_battle_loop` | intro 播完接 loop；教学时 Music -6dB |
| 终局 / 退出战斗 | `music_battle_outro` 或淡出 | 1.5s 淡出，回菜单接 menu_loop |

- 数据驱动：`Assets/Configs/Audio.json`（场景 → 曲目、淡入淡出、音量偏移）；改曲不改代码。
- **渐进（v2 可选，不在本轮验收）**：同曲拆 stems（base/perc/melody），`PlayScheduled(dspTime)` 同步，
  按局势（回合数/血量差/斩杀线）淡入淡出层；v1 只做 intro→loop。
