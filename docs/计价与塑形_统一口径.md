# 计价与塑形 · 统一口径（2026-11-23 定案；2026-11-24 A4 单价改版）

> **一句话**：牌价系统（`CardCostService`）与奖励塑形（`FieldValueReward`）不是两套东西——
> 塑形就是把**同一套标价**用到「双方盘面」上。任何一项在牌价里有价，在塑形里就必须有同一个价；
> 否则 AI 会学到「按塑形而不是按牌理」打。
> 本文是唯一口径来源。改动费率请同批改这里 + `FieldValueReward` 权重表 + `红绿0胜归因_修改计划.md` §3.5。
> **2026-11-24 A4（回到一期训练目标）单价改版**：手牌 **3/张固定**、地牌 **2/块**（横置净 +1），
> 不对关键牌做特殊约束——§1/§2/§3 已按新单价重算；§2 现状表同批订正两处「文档与代码不符」
>（旧表写 地 1.0、手牌 1.0×DerivedTier，实装从来是固定加，且 2026-11-23 起地实为 3.0）。

---

## 0. 为什么必须同源

塑形是 `每条奖励 = λ·(Φ' − Φ)`，`Φ = V(我) − V(对手)`。
如果 `V` 里某项的价格与牌价不一致，模型就会对着**错的价目表**做决策：

| 症状 | 走过的弯路 |
|---|---|
| 绿不铺地、不出大哥 | 地价 0.6 且**横置=0**（用资源就掉分）→ 模型不敢横置、不敢铺 |
| 绿/蓝不叠甲 | **护甲根本不在 Φ 里**（收益 0） |
| 血偿 0 次 | 手牌按 `DerivedTotal`（含代价价）计价 → 代价被收两遍 → 血偿 = −2 永不出手 |
| 模型偏冲脸不解场 | 战斗伤害也按 1.0/点 → 攻击被高估一倍 |

全部已修，见 §2 权重表。

## 1. 标的物与单价（单位统一 = **费**）

| 标的 | 单价 | 牌价侧对应 | 备注 |
|---|---|---|---|
| 卡在手牌 | **3.0 / 张（固定）** | **无对应（有意脱钩，A4 2026-11-24）** | 旧「卡面费 `DerivedTier`」口径（2026-11-23 写下）**从未实装**——代码恒为每张固定加，废弃。与「超出 7 上限部分回合末先 +3 后 −3」自洽（囤牌不赚） |
| 卡进墓地/回手 | 回手 +3；墓地 0 | — | "从墓地回收"收益 = 固定 3/张 |
| 牌库抽牌 | +3（牌进手） | — | 抽到的牌按手牌计（固定） |
| 地牌（池中） | **2.0 / 块** | 无（地不是卡费） | **横置不打折**：地价恒定。旧 3.0（2026-11-23 复利资本化）A4 降回 2——囤地收益过高 |
| 产出元素（临时彩 / Any） | **1.0 / 个** | 1 费 | 于是"横置一块地"净 **+1**（地不变、元素 +1） |
| 生命 | **1.0 / 点** | 1 伤 = 1 费 | |
| 护甲 | **1.0 / 层** | 1 甲 = 1 费 | 旧版缺失 |
| 场面生物 | **(攻 + 血) × 0.5** | 1/1 = 1 费 | 非生物仍按标价 `DerivedTier` |
| 指示物 | ±0.5 / 层（+1/+1 记双倍） | — | 沿用旧值 |
| **法术/效果伤害** | **1.0 / 点** | 1 伤 = 1 费 | 一次性，按牌收费 |
| **战斗伤害** | **0.5 / 点** | — | 生物自带"复利"：属性值已按永久盘面计，攻击每回合重复兑现，不再按 1.0 重复计 |

**复利口径**：生物的攻击/守卫价值体现在 `(攻+血)×0.5` 这个**永久**盘面值里，每回合重复兑现；
战斗伤害只额外补 0.5/点的一次性收益。所以「砍脸」不如「解场」——解场同时拿走对手的复利资产。

### 2.1 势能（状态函数）

`FieldValueReward.ResourceValue / CardDynamicValue`：

| 权重 | 值 | 说明 |
|---|---|---|
| `LifeWeight` | 1.0 | 旧 0.15 |

| `ManaWeight` / `WildManaWeight` | 1.0 / 1.0 | 旧 0.4 / 0.6 |
| `LandTokenWeight` | **2.0**（A4 2026-11-24） | 3.0→2.0；**横置不减价**。（订正：本表 2026-11-23 版误写 1.0——实装当日即为 3.0，文档从未对上） |
| `HandWeight` | **3.0（每张固定，不乘 `DerivedTier`）**（A4 2026-11-24） | 1.0→3.0。（订正：本表 2026-11-23 版写「1.0 × DerivedTier」与代码不符——实装恒为 `value += HandWeight` 固定加） |
| `BioStatWeight` | 0.5（生物按攻+血） | 2026-11-23 新增 |
| 塑形 `includeHand` | **true** | 旧 false（2026-09-22 防摸牌刷分；λ 已 0.05→0.005） |

### 2.2 战斗伤害 0.5 修正（事件层）

Φ 分不出伤害来源，故用引擎事件定向修正（`TideHeadlessDriver`）：

```csharp
EventManager.Instance.Subscribe<CombatDamageEvent>(OnCombatDamage); // 记 打到我 / 打到对手
delta += 0.5f * (打到我方的战斗伤害 − 打到对手的战斗伤害);
reward = λ · delta;
```

- 打到对手：Φ 已 +1.0/点 → −0.5 → 净 **0.5**
- 自己挨打：Φ 已 −1.0/点 → +0.5 → 净 **−0.5**
- `DamageEvent`（法术/效果）不进修正 → 保持 **1.0**

## 3. 自洽性验算（A4 2026-11-24 按新单价重算；分项列出，手牌=固定 3、地=2、元素=1）

| 动作 | Φ 变化（分项） | 判读 |
|---|---|---|
| 抽一张卡（任意费） | **+3** | 固定价——与卡面费脱钩，抽牌恒为加分项 |
| 从墓地回收一张卡 | **+3** | 同上 |
| 把任意卡当土地打出（付 0） | −3（手）+2（地）= **−1** | 之后每横置 +1：**1 次打平、2 次起净赚** |
| 横置一块地 | **+1** | 地价不变 + 元素 +1（A4 口径锚点） |
| 打 3 费 3/3 生物（付 3 元素） | −3（手）−3（付）+3（盘面）= **−3** | 盘面收益须 ≥ 3+费 才为正——固定手牌价的口径后果（用户定案，不对关键牌特殊约束） |
| 打 1 费小精灵（1/1 +1 甲，付 1） | −3（手）−1（付）+1（生物）+1（甲）= **−2** | 低费小生物单步为负；正收益来自后续横置/场面复利 |
| 血偿（3 费、5 伤、吃己方 1/1） | −3（手）−3（付）+5（伤）−1（吃）= **−2** | 代价只收一次（生物消失）；换大伤害/斩杀才赚 |
| 活体炸弹（0 费、参照攻伤害、吃己方生物） | −3（手）+ 参照伤害 − 生物属性 | 用便宜生物换大伤害才赚 |
| 攻击 1 点（战斗伤害） | **+0.5** | 复利已在生物属性里（口径不变） |
| 解场：打死对手 3/3 | **+3**（拿走其盘面值） | 解场 > 砍脸（口径不变） |
| 手牌 7 张（上限）时手牌项 | **21**；第 8 张仍 +3 | 超出部分回合末弃掉 −3——囤牌不赚不亏、白占一步 |

> A4 数值锚点探针（`TideSim --a4-shaping-probe`，2026-11-24）：手牌 7→21、第 8 张 +3、
> 地 +1 块 +2、横置产色 +1、Any +1 全绿（`.ztmp/a4_shaping_probe.txt`）。

## 4. 已知偏差 / 待办

1. **T5 成长口径**：现有 `land_t1/land_t3` 快照记在"本回合铺地之前"，不判别"是否铺地"。
   待改成「T5 地数 / 累计铺地次数」。
2. **血偿可用性**：v3~v6 诊断里血偿 0~1 次，而同局活体炸弹 4~7 次。需单独查 LAE 可用性
   （3 费 + 有可牺牲生物两条件），不是塑形问题。
3. **风险（A4 后已收窄）**：手牌计入势能（true）且每张固定 +3，理论囤牌收益已被**手牌 7 上限封顶**
  （第 8 张回合末先 +3 后 −3，不赚不亏白占一步）；λ=0.005 已比 2026-09-22 事故时小 10 倍。
   若 `ep_len` 仍明显抬头，回滚点=`TideHeadlessDriver` 两处 `includeHand`（计划风险节：单因子
   回滚顺序=先塑形单价 → 再 A6 → 再逐张弃）。
4. **风险**：0.5 战斗伤害若仍导致"无脑冲脸"，则需给"己方生物被消灭"加权或再降战斗伤害。
   A4 追加：固定手牌价使「打小生物」单步为负（§3），若训练中表现为「不出小生物」，属口径后果
   而非缺陷——按停训线带数据找用户定，不自行加关键牌特殊约束。
