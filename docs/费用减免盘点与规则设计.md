## 4. 规则设计：三类显性减免「独立、同类只一次」

### 4.1 备选模型（**仅留档，本批不采用**）

> 2026-11-18 用户定：毛价=无减免按现有规则硬算，目标数量（全域）没问题，隐藏减价全不动。
> 下面只是将来若要「同类只一次」时的一个可选实现思路，**本批不实施**。

1. 毛价 Gross：所有原子按现有硬规则（含分支奖励/引擎奖励按现行为）计算。
2. 若将来要收口，可对每个减免类别只在毛价上算一次最优节省（`S_branch` 最贵一条 / `S_qty` 全卡一次 / `S_timing` 最低 f 一次），
   卡价 = max(0, Gross − ΣS)。
3. 衍生物 D4 固定 +2/只，不参与任何类别。
4. 该模型与「乘法叠加」的区别：加法避免异类减免互相放大；但**本批不引入**，现有价格保持不变。

### 4.2 「同类只一次」的定位（本批只留审计口径）

- 用户确认：**毛价=无减免按现有规则硬算**；目标数量（全域）没有问题；分支/隐藏减价全部不动。
- 因此本批**不引入**「毛价 −Σ节省」的加法账本，也不改任何减价公式；
  「同类只一次」仅作为**审计规则**保留：检查同一类别是否在两层各乘了一次（例如锚价 ×f 又在宿主 ×f、数量档 ×在原子又在卡面），
  发现即告警，不自动改价。
- 将来若要收口，可再讨论「分支只免一条 / 数量全卡一次 / 时机全卡一次」等口径（本文档保留为备选）。

### 4.3 法术主动效果 ×0.9（**TODO · 未实施**）

  技能发动走 `DeriveElementCosts` 直算、不经过卡费口，天然不吃该系数。
